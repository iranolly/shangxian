上线助手（免安装版）v<版本>

项目地址
  https://github.com/iranolly/shangxian
  新版本下载、使用手册、问题反馈都在这里。

使用方法
  1. 将整个文件夹解压到目标位置（请勿只复制 app.exe，cli.exe 需与 app.exe 位于同一目录）
  2. 双击 app.exe 即可使用

数据存放位置
  本文件夹内的 data 文件夹（配置、密钥、日志均存放在其中，复制整个文件夹即可完成迁移）
  文件夹内有一个 shangxian.portable 空文件：存在时，程序将数据存放于 data 中；
  删除后，程序恢复为常规方式（数据存放至系统用户目录）。

如何彻底删除
  1. 先在应用内关闭「开机自动启动」
  2. 退出应用（在托盘图标上点击右键 → 退出）
  3. 删除整个文件夹

安全提醒
  data 文件夹内含 SSH 私钥，请勿将整个文件夹发送给外部人员
  本版本未进行代码签名，Windows 可能提示「未知发布者」→ 点击「更多信息」→「仍要运行」

校验（可选）
  同一批下载中包含 SHA256SUMS 文件，用于确认下载完整、未被替换：
  在 Git Bash 中（先 cd 到下载目录）：sha256sum -c SHA256SUMS
  在 PowerShell 中：Get-FileHash .\shangxian-v<版本>-portable.zip -Algorithm SHA256
  校验和仅保证「下载完整」，无法防止钓鱼，也无法防止安装包被恶意替换。
