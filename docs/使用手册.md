# 上线助手 · 使用手册

（这本手册写给完全不懂技术的用户。每一段都能照着做。）

---

## 一、这个软件是干什么的

一句话：**把你电脑上的程序发布到公网，给一个网址，别人用浏览器就能打开；程序掉了帮你拉起来，连接断了自动重连。**

流程示意（从下往上看）：

```
        你的电脑                          云服务器                     别人
 ┌──────────────────┐            ┌────────────────────┐       ┌─────────────┐
 │ 你的程序          │            │                    │       │             │
 │ 本机端口 8188     │←─ 加密通道 ─│ 云端端口 13000     │← 网址 ←│  浏览器      │
 │ （网站/NAS/工具） │            │ nginx（接待员）     │       │ 手机 / 电脑  │
 └──────────────────┘            └────────────────────┘       └─────────────┘
         ▲
         │ 看护：程序掉了自动拉起来
  ┌──────────────┐
  │   上线助手     │  ← 就是这个软件，住在电脑右下角的托盘里
  └──────────────┘
```

### 先认识 5 个词（后面一直用）

| 词 | 大白话解释 |
|---|---|
| 本机端口 | 你电脑上这个程序的门牌号。比如 ComfyUI 是 8188 |
| 云端端口 | 云服务器上的一个门牌号。比如 13000。外人不直接用它，只是内部转接用 |
| SSH | 一条从你电脑到云服务器的加密通道。Windows 自带，不用另外装 |
| nginx | 云服务器上的「接待员」：别人访问网址，它把请求转给你的电脑 |
| 发布隧道 | 就是「把本机端口接到云端端口」的这条线路。也简称「隧道」 |

### 它不做什么（先说清楚，免得误会）

- 不在云服务器上装任何常驻程序。云端还是原来的「SSH + nginx」。
- 不自动改你的域名解析。要自己去买域名的地方加一条 A 记录，指向服务器 IP。
- 不自动改云端 nginx。它会生成一段配置，你复制粘贴到面板里。
- 不会把这个软件的管理界面暴露到公网。

## 二、第一次用：照着走五步

### 第 0 步：先准备 3 样东西

| 要准备的 | 说明 |
|---|---|
| 一台云服务器 | 你能用 SSH 登录它；上面有 nginx（小皮面板）；服务器上有 `openssl` 命令（多数服务器自带） |
| 一个域名（推荐） | 在卖域名的地方加一条 A 记录，指向你的服务器 IP（A 记录就是告诉域名：访问这个网址时去找哪台服务器）。没有域名也能先发布，只是没有网址可填 |
| 你电脑上的程序先跑起来 | 记住它的端口，比如 ComfyUI 是 8188 |

### 第 1 步：加云端服务器

1. 点电脑右下角托盘里的「上线助手」图标，打开主界面。
2. 点左侧的 **「云端服务器」**。
3. 点右上角的 **「+ 添加服务器」**。
4. 按下面填：

| 字段 | 填什么 | 例子 |
|---|---|---|
| 名字 | 自己好认就行 | 香港-1 |
| 服务器地址 | 服务器 IP 或域名 | api.example.com 或 1.2.3.4 |
| 登录账号 | 你 SSH 登录用的用户名 | user |
| SSH 端口 | 不填默认 22 | 22 |
| 密钥文件（可留空） | 你 `~/.ssh` 里的私钥文件 | C:\Users\你\.ssh\id_ed25519 |

5. **没有密钥怎么办？** 先点弹层右下角 **「保存」**（弹层会关掉），再在服务器卡片上点 **「编辑」**——「没有密钥？」区域里就有 **「用密码登录一次，帮我配好免密」**，输入服务器的登录密码。等一下会显示「配好了！」。
   - 密码只在内存里用一次，不会存下来、不会写进日志。
   - 以后连这台服务器都用自动生成的密钥（存在 `%APPDATA%\Shangxian\keys\` 里）。

> 小提示：如果服务器不允许用密码登录，会提示你手动配密钥。那就把服务器的管理员叫来，或者跳过这步、直接填密钥文件。

### 第 2 步：加本机服务

1. 点左侧 **「本机服务」**。
2. 点右上角 **「+ 添加本机服务」**。
3. 弹层右边会列出 **「本机正在监听的端口」**——在上面找到你的程序（比如 8188），**点一下**，端口、启动程序、名字会自动填好。
4. 再按需补下面几项：

| 字段 | 填什么 |
|---|---|
| 名字 | 好认就行，只有你自己看得到。比如 comfyui |
| 本机端口 | 程序的门牌号。点上面的列表会自动填 |
| 启动程序 | 程序的 exe 或脚本路径。**留空 = 只监控，不帮你启动** |
| 启动参数 | 传给程序的参数。比如 `-m http.server 8188`。可留空 |
| 工作目录 | 程序从哪个文件夹开始跑。可留空 |
| 看护 | 勾上 = 程序掉了自动拉起来 |
| 开机自启 | 勾上 = 应用启动后帮你把这个程序跑起来（需要填了启动程序） |
| 备注 | 给自己看的。可留空 |

5. 点 **「保存」**。

> 老脚本（pi-web、karryn viewer 那套）先别停。新工具跑稳了再停旧的。

### 第 3 步：发布隧道

1. 点左侧 **「发布隧道」**。
2. 点右上角 **「+ 发布新隧道」**，一共 3 步：

**第 1 步（共 3 步）：发布电脑上的哪台服务？**
- 点一下你要发布的服务。它没在跑的时候，别人访问会失败。

**第 2 步（共 3 步）：从哪台服务器出去、别人用哪个网址？**

| 字段 | 怎么填 |
|---|---|
| 云端服务器 | 下拉选一台（第 1 步加好的） |
| 云端端口 | 一般不用改，已经帮你挑了一个没人用的（从 13000 开始找） |
| 别人访问时用的网址 | 填你的域名，比如 comfy.example.com。可留空。填了要去域名商那里加一条 A 记录 |

**第 3 步（共 3 步）：谁能访问？**（很重要）

| 开关 | 意思 | 建议 |
|---|---|---|
| 要密码才能进 | 打开网址要先输用户名和密码 | **推荐**，默认已经打开，密码是自动生成的 |
| 只允许指定 IP 访问 | 只有你写的 IP 能进 | 适合固定上网地点的场景 |
| 两个一起开 | 既要输密码、又得来自你写的 IP，两个条件都得满足 | 最严；在家用宽带 IP 会变的话先别锁死 |
| 两个都不开 | 谁知道网址谁都能进 | ⚠ 界面会标红，别放私人内容 |

两个开关可以任意组合，建好之后也能随时到「访问保护」页改。

> ⚠ 第 3 步这一步就要定好保护：开着「要密码才能进」时，发布时会先在服务器上把密码存好，连不上服务器会直接拦住、不创建隧道（不会先建好再让你稍后补）。服务器暂时连不上就先关掉密码，建好后再到「访问保护」页补也不是不行（推荐还是先把服务器修通）。

3. 点 **「开始发布」**。
4. 成功屏出现 **「发布成功，现在就能访问了」**。**密码只在这里显示一次**，点「复制密码」抄下来存好。

### 第 4 步：把新增的 nginx 几行加到云端

1. 在隧道卡片上点 **「⋯」→「云端配置（nginx）」**。
2. 弹层里是**要新增的几行**（点「复制这段」）+ 一张**简短示意图**：灰色是原配置的样子，高亮是新增内容该放的位置（`...` 表示你原有配置的其它部分）。**不需要替换整段配置。**
3. 登录小皮面板 → 找到这个域名的站点：
   - **反向代理**：目标填 `http://127.0.0.1:云端端口`（之前配过就跳过）。
   - **配置修改**：把复制的几行粘到示意图对应的位置，保存：
     - 密码两行放 `server_name` 下面；
     - 如果开了「只允许指定 IP」，还有 `allow 你的IP;` 和 `deny all;` 几行，也放在同一层；两个都开时密码和 IP 两个条件都要满足；
     - 开着「要密码」时，`auth_basic off;` 放进 `/.well-known/`（证书验证目录）里——这是为了证书到期能自动续，别漏；只开「只允许指定 IP」时没有这一行。
4. 保存后 **重载 nginx**。
5. 如果弹层里还有 **「密码文件内容」**（像 `用户名:$apr1$...` 这样一行）：
   - 把它保存成服务器上的文件 `/xp/panel/vhost/你的域名.htpasswd`（没有这个文件就新建一个，一行就够）。`$apr1$` 后面那串是加密后的密码，不是明文。

> 每次改了访问保护（加/减密码、加/减 IP 白名单）、改了云端端口，都要重新做一遍第 4 步，否则云端还是旧配置。

### 第 5 步：访问验证

1. 用电脑浏览器打开 `https://你的域名`，输用户名密码，看到内容 = 成功。
2. 手机关掉 Wi-Fi、用移动网络再开一次（确认公网真的能进）。开了「只允许指定 IP」时，手机不在白名单里进不去是正常的，用白名单里的网络试。
3. 回到应用看状态：
   - 「本机服务」页显示 **在跑**；
   - 「发布隧道」页显示 **正在发布**。

### 卡在哪一步了？快速对照

| 现象 | 先看哪里 |
|---|---|
| 找不到「本机正在监听的端口」 | 程序是不是还没启动？先把它跑起来再回来点 |
| 保存服务器时提示要密码登录 | 服务器不允许密码登录，改用手动配密钥 |
| 发布隧道时提示端口已被占用 | 换一个云端端口再发布 |
| 网址打不开 | 看第四章「四种常见问题」第 1 条 |

## 三、每个页面、每个字段说明

### 3.1 本机服务页

页面标题「本机服务」，说明：*这台电脑上的程序：记下端口和启动方式，就能帮你启动、看护。* 右上角两个按钮：**「导入现有脚本」**、**「+ 添加本机服务」**。

**卡片上每样东西：**

| 位置 | 内容 | 意思 |
|---|---|---|
| 最左边圆点 | 彩色圆点 + 状态词 | 状态永远有三样：颜色 + 中文词 + 一句人话 |
| 名字 | 比如 comfyui | 你登记时起的名字 |
| 按钮 | 启动 / 停止 | 只有填了「启动程序」才显示。只监控的服务没有这个按钮。停止时如果端口上不是本应用**这次**启动的进程（包括上次退出后留下、这次被认领的），会先弹确认框，确认后才真的关掉 |
| 「⋯」菜单 | 编辑本机服务 / 看程序日志 / 删除本机服务 | 点开就能操作 |
| 第二行 | 本机端口 · 启动程序 或 只监控，不帮你启动 · 备注 | 一眼看清它是谁 |
| 第三行 | 看护 ☑ / 开机自启 ☑ / 已发布到 N 条隧道 | 两个开关随时可以拨 |
| 修复带 | ⚠ 原因 + 按钮 | 出问题时才出现，最多两个按钮 |

**五个状态词（颜色圆点旁边的字）：**

| 状态词 | 意思 | 你能做什么 |
|---|---|---|
| 在跑 | 程序在跑，端口也通 | 不用管 |
| 正在启动 | 程序已经拉起来，正在看端口通不通，等几秒 | 等几秒 |
| 没启动 | 程序没在跑 | 点「启动」（要填过启动程序） |
| 进程在但端口不通 | 程序还在，但它监听的不是这个端口 | 点「改端口」，或看程序日志 |
| 起不来（已停止自动重试） | 程序启动失败，已经停止自动重试 | 点「再试一次」、看日志，检查启动程序/参数/工作目录 |

**添加 / 编辑弹层里的字段：**

| 字段 | 说明 |
|---|---|
| 名字 | 不能为空。点端口列表会自动填 |
| 本机端口 | 要填 1~65535 的数字。同一台电脑上不能有第二个服务用同一个端口 |
| 本机正在监听的端口 | 点一行，自动填「端口 + 启动程序 + 名字」，接着自动读取启动参数和工作目录；填完还能手动改。读不到就先启动程序 |
| 启动程序（可留空 = 只监控不启动） | 留空的话只能看状态，启动、看护、开机自启都用不上 |
| 启动参数（可留空） | 两行文本框；点端口行会自动读取正在跑的那条命令的参数。手填时注意：引号里以反斜杠结尾要写成两个（例 `"D:\data\\"`），否则按 Windows 引号规则，结尾那个 `\` 会把引号转义掉，参数就变形了 |
| 工作目录（可留空） | 程序从哪个文件夹开始跑。自动读取到的是它**现在**的工作目录（程序自己切过目录的话会变） |
| 看护 | 勾上 = 程序掉了自动拉起来 |
| 开机自启 | 勾上 = 应用启动后帮你跑起来 |
| 备注（可留空） | 给自己看 |

**自动读取启动方式（点端口行之后）**：

- 先照旧把「端口 + 程序 + 名字」填上，然后去读正在跑的那个进程是怎么启动的，把「启动程序 / 启动参数 / 工作目录」补全。
- 自动填过的字段旁边会显示「自动读取 · 未验证」小标签；你一手动改，标签就消失。
- **编辑旧服务时**：如果这几个字段里已经有内容，会先问一句要不要用读到的内容覆盖；点取消就保留你原来的，启动程序/参数/工作目录**三个字段都保持原样**（不会只换掉其中一个）。
- **读到的信息不可靠就不覆盖**：端口被多个进程占用、占用进程已经退出、端口换了主人、进程号对不上——这些情况一个字都不填，只在警告区告诉你原因，你自己决定怎么办。
- **疑似密钥会拦住保存**：参数里像是带了密钥（`--token`、`password=` 这类）会红字提醒，并出现勾选框「我知道这些参数里有疑似密钥，仍然保存」；不勾选，保存按钮点不了。
- **参数没自动填时能看原文**：参数里含换行/制表符或太长时，应用不会把它填进配置，而是在警告区只读显示「读取到的原始命令行」（最多 3 行，可复制），方便你照着改。
- **实际会执行的命令行**：启动参数下面有一行只读小字，显示最终会执行的命令（`.bat` / `.ps1` / `.sh` 会显示实际用 `cmd` / `powershell` / `bash` 包装后的样子），读不到就不显示。

**参数引号小知识**：Windows 传参时，引号里以反斜杠结尾的写法（如 `"D:\data\"`）会把结尾引号转义掉，参数会变形。要让参数以反斜杠结尾，写两个：`"D:\data\\"`。

**已登记端口会跳去编辑**：端口如果已经登记在别的服务名下，那一行会标出「已登记：名字」。点它不会在这里重复登记，而是直接跳到那台服务的编辑界面，并自动读取补全（新建服务时也有这段说明）。

**停止确认（人话版）**：点「停止」时——

- 是应用自己启动的进程：直接停，不啰嗦。
- 是你自己手动开的程序在监听这个端口：应用不会直接动手，会弹确认框告诉你「这台服务不是你启动的，正在监听的是 xxx.exe（PID 1234）。停止会真的把它关掉，确定吗？」。确认才真的关掉，取消就什么都不做。**上次应用退出后留下的进程**下次启动时就算被按端口认领了，停止时也算「不是这次启动的」，同样要先确认。
- **启动程序是包装脚本时**（`.bat` / `.ps1` / `.sh` 等，真正监听端口的是脚本拉起的子进程）：应用会把自己启动的这棵进程树（脚本 + 子进程）一起停掉，所以不会因为是子进程在监听就误弹「这不是你启动的」确认框；已经脱离出去、追不到的进程才会按外部进程弹确认。
- 失败时把原因直接写在卡片上，不弹看不懂的报错。

**导入现有脚本**：会扫描你以前的两个旧启动脚本（pi-web 和 karryn viewer 的路径），读出端口和目标服务器，生成「一台本机服务 + 一条已暂停的隧道」。**导入后隧道是暂停的**，确认新工具跑稳、停掉旧脚本之后，再去「发布隧道」页点「开始发布」完成接管。启动方式不会自动接管，需要到本机服务页补上。

**删除本机服务**：会弹确认框。如果还有隧道在用它，程序会拦下来并告诉你哪几条隧道，先删隧道再删服务。它不会自动连带删。

### 3.2 发布隧道页

页面标题「发布隧道」，说明：*把某台本机服务接到某台云端服务器上，别人用网址就能打开。* 右上角 **「+ 发布新隧道」**。

**卡片上每样东西：**

| 位置 | 内容 | 意思 |
|---|---|---|
| 圆点 + 状态词 | 见下面的五状态表 | |
| 按钮 | 暂停 / 开始发布 | 暂停后别人就打不开了 |
| 「⋯」菜单 | 立刻重连 / 编辑隧道 / 云端配置（nginx）/ 看发布日志 / 删除隧道 | |
| 第二行 | 服务名 → 服务器名 · 云端 端口 · 网址 | 一眼看清从哪到哪 |
| 黄色小条 | 本机服务没在跑（访问会失败，先去看本机服务页） | 问题在源头，不在隧道 |
| 修复带 | ⚠ 原因 + 「立刻重连」「看日志」 | 出问题时才出现 |

> 这张卡片不显示访问保护状态：保护是门禁的事，统一在「访问保护」页看和改。想在发布隧道页复制云端配置，用卡片 ⋯ →「云端配置（nginx）」。

**五个状态词：**

| 状态词 | 意思 | 你能做什么 |
|---|---|---|
| 正在发布 | 别人现在可以访问 | 可以点「暂停」 |
| 连接中 | 正在和云端服务器建立连接，几秒钟就好 | 等几秒 |
| 掉线重连中 | 云端服务器联系不上了，可能网络波动。会自动重试 | 等自动重试，或点「立刻重连」 |
| 出错 | 发布失败 | 点「重试」，或看日志 |
| 已暂停 | 你暂停了发布，现在没人能访问 | 点「开始发布」 |

**新建隧道向导（3 步）：**

| 步骤 | 字段 | 说明 |
|---|---|---|
| 第 1 步 | 选一台本机服务 | 只会发布你选中的这台 |
| 第 2 步 | 云端服务器 | 下拉选一台 |
| 第 2 步 | 云端端口 | 已经帮你挑了一个没人用的（从 13000 开始）。被别的隧道占了会直接说明、下一步点不了 |
| 第 2 步 | 别人访问时用的网址（可留空） | 填了要去域名商加 A 记录 |
| 第 3 步 | 访问保护两个开关 | 要密码（默认开，推荐）/ 只允许指定 IP；两个可以同时开，两个都不开 = 谁都能进 |
| 第 3 步 | 访问用户名、密码、换一个 | 默认用户名 `shangxian`，密码自动生成 16 位 |
| 第 3 步 | 给这条隧道起个名字 | 默认是「服务名 发布」，只有你自己看得到 |

保存成功后：网址和密码只显示这一次（密码），记得复制。

**编辑隧道弹层**（隧道卡片 ⋯ →「编辑隧道」；只改发布相关的东西）：

| 字段 | 说明 |
|---|---|
| 隧道名字 | 不能为空 |
| 公网网址（可空） | 你的域名 |
| 云端端口 | 改了保存后会断开重连一次 |

弹层里没有访问保护：保存时保护设置原样保留，改名字/网址/端口不会误动密码或 IP 白名单。要改保护，去「访问保护」页。

**怎么核对云端实际生效的保护（「检查云端」按钮）：**

1. 应用里显示的「当前设置的保护」只是你希望的状态；云端真的有没有生效，到「访问保护」页点那一条的「检查云端」。
2. 应用会 SSH 到云端，读这个域名的站点配置和密码文件，然后告诉你：要不要密码（开/关）、IP 白名单（开/关、里面有几个 IP）、密码文件在不在。
3. 显示的和应用里设置的对不上（常见：贴了片段没重载、换了密码没重贴、白名单忘了改），按提示重新走一遍第 4 步，把新片段贴到面板里，再点一次「检查云端」确认。

### 3.3 云端服务器页

页面标题「云端服务器」，说明：*一台一直开着的电脑，负责把别人的访问转给你的电脑。* 右上角 **「+ 添加服务器」**。

**卡片上：** 名字、`登录账号@地址:端口`、`密钥 路径` 或 `默认密钥`；两个按钮「编辑」「删除」。

**添加 / 编辑弹层字段：**

| 字段 | 说明 |
|---|---|
| 名字 | 自己好认就行 |
| 服务器地址 | IP 或域名 |
| 登录账号 | SSH 用户名 |
| SSH 端口 | 默认 22 |
| 密钥文件（可留空） | 留空就用系统默认密钥（`~/.ssh` 里那把） |

**「没有密钥？」区域（重要，第一次用很方便）：**

- 还没保存过的服务器会提示：*先把这台服务器保存一下，就能用密码自动配好免密登录。*
- 保存后重新点卡片上的「编辑」，就会出现按钮 **「用密码登录一次，帮我配好免密」**。输入服务器的登录密码，程序会：生成一把专属密钥 → 用密码登录一次 → 把公钥写到服务器上 → 立刻用密钥验证一次。
- 成功后密钥存在 `%APPDATA%\Shangxian\keys\`，以后这台服务器都走密钥，不再用密码。
- 密码只在内存里用一次，不会存下来。

**删除服务器**：如果还有隧道挂在这台服务器上，程序会拒绝，提示「还有隧道挂在这台服务器上，先处理它们」。先删隧道，再删服务器。

### 3.4 访问保护页

页面标题「访问保护」，说明：*给每条隧道加一道门：要密码、只让指定的人进，两种保护可以同时开。* 这一页只管门禁：**网页访问密码、IP 白名单、核对云端是否生效**；发布、启停、改名/网址/云端端口都在「发布隧道」页。

- 顶部一张「保护情况」卡片：全部有保护时显示「N 条隧道都设了保护。」；否则显示「有 N 条隧道还没设好保护，网址一泄露谁都能看。」
- 下面每条隧道一行：隧道名、网址（没填就显示「还没填公网网址」）、保护方式小标签、「检查云端」按钮、一个保护按钮（按当前状态显示「加保护」「改密码 / 用户名」「改白名单」「改保护」）。

**保护按钮打开的弹层**（访问保护专用，只在这一页出现）：

| 字段 | 说明 |
|---|---|
| 要密码才能进（推荐） | 打开 = 别人打开网页要先输用户名和密码 |
| 访问用户名 | 打开「要密码」时显示，默认 `shangxian`，可以改 |
| 新密码 | 打开「要密码」时显示。**留空 = 沿用原来的密码**；填了就用新的 |
| 只允许指定 IP 访问 | 打开 = 只有你写的 IP 能进，在下面填，逗号分隔，比如 `1.2.3.4, 5.6.7.8` |
| 两个都不开 | ⚠ 弹层里会标红提醒：谁知道网址谁都能进 |

- **保存成功后会自动打开这条隧道的「云端配置」**：把新的几行贴到服务器面板里并重载 nginx，保护才算真的生效（这是设计好的下一步，别跳过）。
- 密码不存本地，只存加密结果，找不回原文；忘了就在这个弹层里填一条新密码保存。

**标签和按钮对照：**

| 标签 | 意思 | 按钮 |
|---|---|---|
| 要密码（用户名 xxx） | 已经设好密码 | 改密码 / 用户名 |
| 选了要密码，但还没设 | 缺密码，别人现在进不来也不安全 | 改密码 / 用户名 |
| 仅白名单 IP（N 个） | 白名单里有 N 个 IP，只有它们能进 | 改白名单 |
| 仅白名单 IP（还没填 IP） | 开了白名单但一个 IP 都没填，别人进不来 | 改白名单 |
| 密码 + IP 白名单 | 两个都开了，两个条件都要满足 | 改保护 |
| 密码 + IP 白名单（还没设密码） | 白名单有了，密码还没设 | 改保护 |
| 无访问保护 | 没有任何保护 | 加保护 |

- 这一页每行**没有单独的「云端配置」按钮**（改完保存会自动打开）；想看/复制云端配置也可以到「发布隧道」页卡片 ⋯ →「云端配置（nginx）」。
- 页面底部提醒：*这里的密码是别人打开网页时输的；连服务器用的登录密码在「云端服务器」页。密码不会存在本地（只存加密结果），忘了就在这里重新设一个；保存成功后直接打开的云端配置里，记得把新片段贴到面板里，再点「检查云端」确认真的生效了。*

|---|---|
| 外观 | 跟随系统 / 浅色 / 深色 三选一 |

### 3.6 四个弹层

**发布日志 / 程序日志**（隧道卡片 ⋯ → 看发布日志；本机服务卡片 ⋯ → 看程序日志）：

- 显示最近 300 行。
- 发布日志 = 这条隧道和云端服务器的连接记录。
- 程序日志 = 程序自己打印的内容，还有看护记录（启动、退出、自动重启等）。
- 出问题时把它复制出来，定位问题最快。

**云端配置（nginx）**：显示使用步骤、nginx 片段（可复制）、密码文件内容（如果设了访问保护）。密码文件是 htpasswd，给别人打开网页时用，不是服务器登录密码。

## 四、四种常见「出问题」怎么办

### 问题 1：网址打不开

别急，按顺序查（前一步没问题再看下一步）：

| 顺序 | 检查什么 | 怎么查 | 正常应该是什么样 |
|---|---|---|---|
| 1 | 应用还在吗 | 看右下角托盘有没有「上线助手」图标 | 有；没有就打开它 |
| 2 | 本机程序在不在 | 「本机服务」页看状态 | 在跑 |
| 3 | 程序本身好的吗 | 在电脑浏览器打开 `http://127.0.0.1:你的本机端口`（比如 `http://127.0.0.1:8188`） | 能打开 |
| 4 | 隧道开着吗 | 「发布隧道」页看状态 | 正在发布。已暂停就点「开始发布」；掉线重连中就等一会儿；出错就看 ↳ 后面的原因 |
| 5 | 云端 nginx 配了吗 | 隧道卡片 ⋯ → 云端配置（nginx），看有没有贴过 | 片段已经贴进面板，并且重载过 nginx |
| 6 | 域名解析加了吗 | 在买域名的地方加 A 记录，指向服务器 IP | 解析生效（有时要等十几分钟） |
| 7 | 密码对吗 | 「访问保护」页看保护方式 | 用对应的用户名密码登录 |
| 8 | 是不是缓存/网络问题 | 换一个浏览器、手机切到流量再试 | 能打开 |

**还不行**：打开该隧道的「看发布日志」，把内容复制出来。

### 问题 2：端口被占

| 情况 | 提示原文 | 怎么办 |
|---|---|---|
| 本机端口被同一台电脑的另一台服务占了 | 本机端口 30141 已经被另一台服务用了 | 到「本机服务」页编辑，换一个端口（程序真的监听的那个） |
| 云端端口被同一台电脑的另一条隧道占了 | 云端端口 19103 已经被这个服务器上的其他隧道用了 | 编辑隧道换一个空闲端口，保存后重新做一遍 nginx 配置 |
| 云端端口真的被别的程序占了 | 隧道日志里出现 `remote port forwarding failed` | 应用会自动清掉「上次遗留的 SSH 连接」（只清占着这个端口、且是 SSH 的，不会乱杀别的程序），然后重连。如果日志写「端口被非 ssh 进程占着」，说明占它的是别的程序，应用不会动它——请换一个云端端口 |
| 两台电脑用了同一个云端端口 | 隧道一直连不通/掉线 | 两台电脑各用各的云端端口，不要重复 |

### 问题 3：掉线重连中

**这是什么**：你电脑和云服务器之间的通道断了。常见原因：网络波动、服务器重启、电脑休眠、安全软件拦截。

**应用会自动做什么**：

- 马上开始重试，第一次等 2 秒，还不通就 4 秒、8 秒……最长 30 秒试一次。
- 连接恢复正常后，状态自己变回 **正在发布**。
- 断掉超过 3 分钟会弹一条系统通知；恢复后再弹一条（可在设置页关掉）。

**你能做什么**：

| 想做的事 | 怎么做 |
|---|---|
| 不想等 | 点卡片上的「立刻重连」 |
| 想知道为什么 | 点「⋯」→「看发布日志」，看最后几行 |
| 断了很久 | 看看云服务器还开着吗、密码/密钥是不是换过、家里的网是不是断了 |

**注意**：断线期间，别人打开网址会失败（常见的是 502 错误）。这不是程序坏了，等隧道恢复就好。

### 问题 4：密码忘了

| 忘了哪个密码 | 能不能找回 | 怎么办 |
|---|---|---|
| 网址的访问密码 | **找不回**。程序只存加密结果，不存原文 | 「访问保护」页 → 行按钮（改密码 / 用户名）→ 填一条新密码保存；保存后会自动打开「云端配置」，**把新的密码文件行贴回面板并重载 nginx**，否则旧密码还有效 |
| 云服务器的登录密码 | 跟本软件无关 | 找服务器商家/管理员重置 |
| 免密登录失效（换了密钥、服务器重装） | 不用找回 | 「云端服务器」页 → 编辑 → 点「用密码登录一次，帮我配好免密」重新配一次 |

## 五、开机自启和托盘

### 托盘是什么

就是电脑右下角（时钟旁边）那一排小图标。上线助手平时就住在这里。

| 操作 | 结果 |
|---|---|
| 点窗口右上角的关闭按钮 ✕ | **只是把窗口收到托盘里，程序不退出**，隧道继续跑 |
| 左键点托盘图标 | 打开主界面 |
| 右键点托盘图标 | 菜单：「打开主界面」「退出并停止全部本地服务」「退出」 |
| 点「退出」 | **只退应用**：SSH 隧道立刻停（别人暂时打不开），但**本机服务继续跑**（保活） |
| 点「退出并停止全部本地服务」 | 先停**本应用自己启动**的本地服务（连着它拉起的整棵进程树），再停**能核对出是这台服务配置的程序**的认领进程，然后退出；核对不过的（比如启动程序填的是 .bat/.cmd 脚本、实际监听端口的是它拉起的子进程）不会硬杀，会保留并弹一条通知告诉你几个没停。适合想一次性收干净的时候 |

> 记住一句话：**窗口关了没事，托盘退了隧道才断；本地服务默认保活，不会被带走。**

### 退出和重启应用时，本地服务会继续跑

本地服务的默认行为是**保活**：应用退出、重启、甚至崩溃或被任务管理器强杀，你电脑上那些本地程序都不会被带走，继续在后台跑。

- **为什么不一起关**：你的程序可能还在给别的用途服务（比如自己本地开发、别的工具在用），不该因为关了助手就被连坐。
- **下次打开会「按端口认领」**：应用探测到端口已经在监听（认领只看端口，不核对是不是你登记的那个程序；核对归属只在停止、杀进程时做），就认成「在跑」，不会再拉一个重复的进程去抢端口。
- **崩溃/强杀也不会清理**：应用没来得及善后时，残留的本地服务不会自动消失。想停掉它们：
  - 正常情况：重新打开应用 → 「本机服务」页 → 点「停止」；
  - 实在打不开应用：用任务管理器结束那几个程序。
- **一键退出并全部停掉**：托盘右键 → 「退出并停止全部本地服务」。它会先把本应用自己启动的本地服务停掉，再停能按程序路径核对出归属的认领进程，然后退出应用；核对不过的绝不硬杀（免得误杀）。退出前会弹一条通知：停掉了几个、有几个没能停（没能停的通常需要手动处理）。
- **编辑启动方式不会杀旧进程**：编辑一台正在跑的服务，保存时如果改了启动程序/参数/工作目录，旧程序**保持不动**，卡片上会提示「启动方式已改；正在跑的程序没有动，改动会在下次重启服务时生效」。点「停止」再「启动」才用得上新配置。
- **停止认领来的进程会先问一句**：如果端口上的程序不是本应用这次启动的（比如上次应用退出后留下的），点「停止」会先弹确认框（写着程序名和 PID），确认后才真的关掉（只关端口上这一个监听进程，不会连它拉起的子进程一起结束）。
- **启动程序填成脚本的，停不掉**：如果「启动程序」填的是 .bat/.cmd/.ps1 这类包装脚本，实际监听端口的是脚本拉起的子进程，核对（要求程序路径与配置一致）过不了，界面「停止」和托盘「退出并停止全部本地服务」都不会硬杀它。想让助手能停，把启动程序改成实际监听者的 exe（比如 node.exe、python.exe）。
- **认领只在应用启动后的第一轮探测做一次**：应用启动时服务正好在重启、端口还没起来，这次就认不到；之后不会自动补认，手动点一次「启动」即可。
- **SSH 隧道不受影响**：隧道跟着应用走，应用一退隧道就断（没有保活）；下次打开应用会按原配置重新连上。

### 设置开机自启

两种自启，别搞混：

| 在哪里开 | 管的是谁 | 效果 |
|---|---|---|
| 「设置」页 → 开机自动启动 | 上线助手自己 | 登录电脑后，应用静默进托盘（不弹窗口），开始看护所有隧道 |
| 「本机服务」页卡片上的「开机自启」开关 | 某个本机程序 | 应用启动后，帮你把这个程序也拉起来（需要填过启动程序） |

想让服务一直在线，推荐：**「设置 → 开机自动启动」打开 + 需要的程序也勾上「开机自启」+ 电脑不关机**。

> 应用的开机自启不需要管理员权限，它只是登记在你自己账号的启动项里（注册表 HKCU Run，项目名 `Shangxian`）。

## 六、数据在哪、怎么备份、怎么搬家

### 数据放在哪

所有东西都在一个文件夹里：

```
%APPDATA%\Shangxian
（实际路径一般是 C:\Users\你的用户名\AppData\Roaming\Shangxian）
```

最快的打开方式：在「设置」页点「配置文件夹」旁边的 **「打开」**；或者在资源管理器地址栏输入 `%APPDATA%\Shangxian` 回车。

| 文件/文件夹 | 里面是什么 | 能删吗 |
|---|---|---|
| `config.json` | 全部配置：服务器、本机服务、隧道、开关 | 删了等于全部重配 |
| `config.json.v3.bak`、`config.json.v4.bak` | 老版本升级时自动留的对应版本备份 | 可以删 |
| `keys\` | 每台服务器一把专属密钥（配免密时生成） | 删了要重新配免密 |
| `logs\` | 日志。隧道日志叫 `<隧道名>.ssh.log`，程序日志叫 `service-<服务名>.log`，应用自己的记录叫 `app.log`（如退出停全部的结果提示发不出去时的兜底） | 会一直追加。太大可以删（最好的做法是先把应用退出再删；应用自己写的日志会重新建文件） |
| `ctl.json` | 应用运行时给命令行工具用的「通行证」 | 应用退出后自动失效，不用管 |

> `config.json` 能手改（改之前先复制一份）。但**手改前先把应用退出**（托盘右键 → 退出），改完再打开应用，免得被覆盖。
>
> 注意：托盘「退出」只退应用，本机服务是保活的、会继续跑。想连本地服务一起停，用「退出并停止全部本地服务」（能核对出归属的会停掉；核对不过的会保留，并在退出通知里提示）。

### 怎么备份

1. 托盘右键 → **退出**（注意：退出后别人就打不开你的服务了）。
2. 把整个 `%APPDATA%\Shangxian` 文件夹复制到 U 盘或网盘。
3. 重新打开应用。

### 怎么搬家 / 换电脑

1. 新电脑先装好上线助手（见第七章）。
2. 打开一次应用，再退出（让它建好文件夹）。
3. 把备份的 `Shangxian` 文件夹复制过去，覆盖新的。
4. 打开应用，重点检查两处：
   - 「云端服务器」页：密钥路径是完整路径，新电脑用户名不一样就可能失效。失效就点「用密码登录一次，帮我配好免密」重新配一次。
   - 「发布隧道」页：确认云端端口和网址没和别的电脑撞。

## 七、第二台电脑怎么装

### 新电脑需要什么

| 要求 | 怎么确认 |
|---|---|
| Windows 10 / 11（64 位） | |
| 开启「OpenSSH 客户端」 | 设置 → 系统 → 可选功能 → 添加功能 → 勾「OpenSSH 客户端」 |
| WebView2（界面组件） | Win11 一般自带；Win10 去微软官网下「WebView2 Evergreen 安装包」装上 |

### 装法

1. 在一台有项目源码的电脑上，用命令行打包安装包：

   ```
   cd app
   npm install
   npm run tauri build
   ```

2. 打包完成后，安装包一般在 `target\release\bundle\` 文件夹里（Windows 下通常是 .msi 和 .exe 两种）。
3. 把安装包拷到第二台电脑，双击安装。
4. 打开后，按第二章「第一次用：照着走五步」重新加服务器、本机服务、隧道。
5. 如果两台电脑共用同一台云服务器，注意：
   - **云端端口不能重复**（一台服务器上同一个端口只能接一条隧道）；
   - **同一个域名只能指一条隧道**；
   - 域名解析记录加一次即可，两台电脑的服务要用不同的子域名（比如 `a.example.com` 和 `b.example.com`）。
6. 也可以把第一台电脑的 `%APPDATA%\Shangxian` 拷过去省事，但记得按第六章「搬家」检查密钥路径。

### 命令行工具（可选的）

`cli.exe` 是给 AI / 自动化脚本用的遥控器，普通使用不需要。如果你要它：

- 它要和应用主程序（`app.exe`、`Shangxian.exe` 或 `上线助手.exe`，看安装后的实际名字）放在同一个文件夹里，这样 `cli.exe app start` 才能把应用叫起来。
- 三个名字都不在时，手动点图标打开应用就行，命令行照样能连上。
- 用法见 `docs/AI-AGENT.md`。

## 八、安全红线（请务必遵守）

| 红线 | 为什么 |
|---|---|
| **绝不暂停 / 重启 / 删除 pi-web 服务和它的隧道** | 那是你正在用的通道，一动就直接断线 |
| 删除本机服务或服务器前，先看有没有隧道引用 | 应用会拒绝并告诉你是哪几条，别绕过去（不要手改配置文件硬删） |
| 网页访问密码（访问保护）只显示一次，只存加密结果 | 忘了只能重设，别指望找回 |
| 配免密用的登录密码只在内存用一次 | 不会落盘、不会进日志 |
| 云端保持「普通 SSH + nginx」，不装常驻程序 | 少装一个东西，少一个故障源 |
| 想让服务常在，用「开机自启 + 托盘」 | 直接退出应用 = 所有隧道全停 |
| 每个服务都加访问保护 | 「谁都能进」= 网址一泄露谁都能看 |
