# 上线助手 · 使用手册

（这本手册写给完全不懂技术的用户。每一段都能照着做。对应版本：v0.6.0。）

---

## 一、这个软件是干什么的

一句话：**把你电脑上的程序发布到公网，给一个网址，别人用浏览器就能打开；程序掉了帮你拉起来，连接断了自动重连。**

流程示意（从下往上看）：

```
        你的电脑                          云服务器                     别人
 ┌──────────────────┐            ┌────────────────────┐       ┌─────────────┐
 │ 你的程序          │            │                    │       │             │
 │ 本机端口 8188     │←─ 加密通道 ─│ 云端端口 13000     │← 网址 ←│  浏览器      │
 │ （网站/NAS/工具） │            │ nginx（接待员）     │       │ 手机 / 电脑  │
 └──────────────────┘            └────────────────────┘       └─────────────┘
         ▲
         │ 看护：程序掉了自动拉起来
  ┌──────────────┐
  │   上线助手     │  ← 就是这个软件，住在电脑右下角的托盘里
  └──────────────┘
```

### 先认识这些词（后面一直用）

| 词 | 大白话解释 |
|---|---|
| 本机服务 / 服务 | 你电脑上的一个程序。记下它的端口和启动方式，助手就能帮你启动、看护 |
| 发布隧道 / 隧道 | 把「本机端口」接到「云端端口」的这条线路，别人访问网址走的就是它 |
| 云端服务器 / 服务器 | 一直开着的那台云服务器，负责把访问转给你的电脑 |
| 本机端口 | 你电脑上这个程序的门牌号。比如 ComfyUI 是 8188 |
| 云端端口 | 云服务器上的一个门牌号。比如 13000。外人不直接用它，只是内部转接用 |
| SSH | 一条从你电脑到云服务器的加密通道。Windows 自带，不用另外装 |
| nginx | 云服务器上的「接待员」：别人访问网址，它把请求转给你的电脑 |
| 访问保护 | 网页访问的门禁：要密码、只让指定 IP 进，两种可以同时开 |
| 检查云端 | 助手连到服务器上，读实际生效的保护，看和你设置的对不对得上 |
| 免密登录 | 用密钥连服务器，不再输密码；密钥由助手自动生成 |
| 密钥 | 存在「数据目录」里的一把文件，相当于服务器的钥匙；不要发给别人 |
| 贴云端配置 | 把助手生成的几行 nginx 配置复制到服务器面板里，再重载 nginx |
| 发布预设 | 云端配置的常用片段：普通网站 / WebSocket / 大文件上传 |
| 看护 | 程序掉了自动拉起来；进程还在但端口不通（假死）也会处理 |
| 体检 | 一键检查整条链路（程序、网络、服务器、隧道、证书），哪一步没过告诉你怎么办 |
| 诊断包 | 一份脱敏的「现场记录」，发给帮你排查的人用；不含密码和密钥 |
| 数据目录 | 存配置、日志、密钥的文件夹；搬家时整个拷走就行 |
| 免打扰时段 | 这段时间只压「掉线」提醒，「恢复」照报；默认关，默认 22:00 到 08:00 |
| 最近删除 | 删掉的东西 10 分钟内还能在这里找回来 |
| 便携版 | 不用安装的版本：解压到哪，数据就在旁边的 `data` 文件夹里 |
| 更新检查 | 去发布页看一眼有没有新版本；只提示，不自动下载、不自动安装 |

### 它不做什么（先说清楚，免得误会）

- 不在云服务器上装任何常驻程序。云端还是原来的「SSH + nginx」。
- 不自动改你的域名解析。要自己去买域名的地方加一条 A 记录，指向服务器 IP。
- 不自动改云端 nginx。它会生成一段配置，你复制粘贴到面板里。
- 不会把这个软件的管理界面暴露到公网。
- 不自动下载、不自动安装新版本。发现新版本只提示，下载安装都归你。
- 远端清理残留只按端口精确清理，绝不按用户名全杀。
- 卸载默认保留配置和密钥；只有你勾选「同时删除配置和密钥」才会删。

## 二、第一次用：照着走五步

### 第 0 步：先准备 3 样东西

| 要准备的 | 说明 |
|---|---|
| 一台云服务器 | 你能用 SSH 登录它；上面有 nginx（一般是小皮或宝塔面板）。不用在服务器上装任何额外程序，密码加密在你电脑上算 |
| 一个域名（推荐） | 在卖域名的地方加一条 A 记录，指向你的服务器 IP（A 记录就是告诉域名：访问这个网址时去找哪台服务器）。没有域名也能先发布，只是没有网址可填 |
| 你电脑上的程序先跑起来 | 记住它的端口，比如 ComfyUI 是 8188 |

还没装软件？看第八章「安装、升级、卸载、便携版」。

### 第 1 步：加云端服务器

1. 点电脑右下角托盘里的「上线助手」图标，打开主界面。
2. 点左侧的 **「云端服务器」**。
3. 点右上角的 **「+ 添加服务器」**。
4. 按下面填：

| 字段 | 填什么 | 例子 |
|---|---|---|
| 名字 | 自己好认就行 | 香港-1 |
| 服务器地址 | 服务器 IP 或域名 | api.example.com 或 1.2.3.4 |
| 登录账号 | 你 SSH 登录用的用户名 | user |
| SSH 端口 | 不填默认 22 | 22 |
| 密钥文件（可留空） | 你 `~/.ssh` 里的私钥文件 | C:\Users\你\.ssh\id_ed25519 |
| 站点目录（可留空） | 面板把网站放在服务器哪个目录；不知道就留空，按小皮面板默认 `/xp/panel/vhost` 找。宝塔等面板填 `/www/server/panel/vhost` | 留空 |

5. **没有密钥怎么办？** 就在这个弹层里找到 **「没有密钥？」** 区域：填服务器的登录密码，点 **「用密码登录一次，帮我配好免密」**。如果这台服务器还没保存过，助手会**先把它保存下来再配**。等一下会显示「配好了！」。
   - 密码只在内存里用一次，不会存下来、不会写进日志。
   - 以后连这台服务器都用自动生成的密钥（存在应用的「数据目录」里，一般是 `%APPDATA%\Shangxian\keys\` 或 `%LOCALAPPDATA%\Shangxian\keys\`；在「设置」页点「打开」就能看到实际位置）。

6. 配好后，在服务器卡片上点 **「测试连接」**：真连一次服务器，成功会显示「连接成功，用时 x.x 秒」。报错会直接说人话（比如端口不对、没配免密、地址解析不了）。

7. **填站点目录（可选）**：不知道就留空，按小皮面板默认 `/xp/panel/vhost` 找；宝塔等面板填 `/www/server/panel/vhost`。生成云端配置、放密码文件、「检查云端」都按这个目录算。

> 小提示：如果服务器不允许用密码登录，会提示你手动配密钥。那就把服务器的管理员叫来，或者跳过这步、直接填密钥文件。

### 第 2 步：加本机服务

1. 点左侧 **「本机服务」**。
2. 点右上角 **「+ 添加本机服务」**。
3. 弹层右边会列出 **「本机正在监听的端口」**——在上面找到你的程序（比如 8188），**点一下**，端口、启动程序、名字会自动填好。
4. 再按需补下面几项：

| 字段 | 填什么 |
|---|---|
| 名字 | 好认就行，只有你自己看得到。比如 comfyui |
| 本机端口 | 程序的门牌号。点上面的列表会自动填 |
| 启动程序 | 程序的 exe 或脚本路径。**留空 = 只监控，不帮你启动** |
| 启动参数 | 传给程序的参数。比如 `-m http.server 8188`。可留空 |
| 工作目录 | 程序从哪个文件夹开始跑。可留空 |
| 看护 | 勾上 = 程序掉了自动拉起来 |
| 开机自启 | 勾上 = 应用启动后帮你把这个程序跑起来（需要填了启动程序） |
| 备注 | 给自己看的。可留空 |

5. 点 **「保存」**。

> 老脚本（pi-web、karryn viewer 那套）先别停。新工具跑稳了再停旧的。想接管旧脚本，点「导入现有脚本」，默认会扫 pi-web 的旧启动脚本，生成一台服务 + 一条已暂停的隧道；确认没问题再去「发布隧道」页点「开始发布」。

### 第 3 步：发布隧道

1. 点左侧 **「发布隧道」**。
2. 点右上角 **「+ 发布新隧道」**，一共 3 步：

**第 1 步（共 3 步）：发布电脑上的哪台服务？**
- 点一下你要发布的服务。它没在跑的时候，别人访问会失败。
- 一台服务都没有？面板上有 **「+ 添加本机服务」** 按钮，加完会自动回到向导并帮你选上。

**第 2 步（共 3 步）：从哪台服务器出去、别人用哪个网址？**

| 字段 | 怎么填 |
|---|---|
| 云端服务器 | 下拉选一台（第 1 步加好的）。一台都没有时有「+ 添加云端服务器」按钮 |
| 云端端口 | 一般不用改，已经帮你挑了一个没人用的（从 13000 开始找） |
| 别人访问时用的网址 | 填你的域名，比如 comfy.example.com。可留空。填了要去域名商那里加一条 A 记录 |
| 发布预设 | 普通网站（默认）/ WebSocket（实时通信）/ 大文件上传；不确定就保持默认 |

**第 3 步（共 3 步）：谁能访问？**（很重要）

| 开关 | 意思 | 建议 |
|---|---|---|
| 要密码才能进 | 打开网址要先输用户名和密码 | **推荐**，默认已经打开，密码是自动生成的 |
| 只允许指定 IP 访问 | 只有你写的 IP 能进 | 适合固定上网地点的场景 |
| 两个一起开 | 既要输密码、又得来自你写的 IP，两个条件都得满足 | 最严；在家用宽带 IP 会变的话先别锁死 |
| 两个都不开 | 谁知道网址谁都能进 | ⚠ 界面会标红，别放私人内容 |

两个开关可以任意组合，建好之后也能在隧道卡片上随时改。

> ⚠ 第 3 步这一步就要定好保护：开着「要密码才能进」时，密码加密是在**你自己电脑上**算好的，不碰服务器、也不用服务器装任何东西；算好之后再建隧道。
>
> 加密结果只是存进本机配置，建隧道这一步本身不连服务器。要是点发布后还是报错，先到「云端服务器」页点一次「测试连接」确认服务器信息没问题，再重试。
>
> 图省事先把密码关掉、建好后再在卡片上补也可以，但不推荐。

3. 点 **「开始发布」**。
4. 成功屏出现 **「隧道建好了，还差最后一步」**——意思是隧道连上了，但**别人还打不开**；必须把第 4 步的云端配置贴到服务器面板、重载 nginx，网址才正式生效。**密码只在这里显示一次**，点「复制密码」抄下来存好。
   - 填了网址的话，成功屏上还有 **「显示二维码」** 按钮，手机扫码就能打开（二维码是本地生成的，不会把网址发到网上）。
   - 点 **「下一步：贴云端配置」** 直接打开云端配置弹层，或者点「稍后再说」。

### 第 4 步：把新增的 nginx 几行加到云端

1. 在隧道卡片上点 **「⋯」→「云端配置（nginx）」**。
2. 弹层里是**要新增的几行**（每段高亮旁有小「复制」按钮，点一下即复制）+ 一张**简短示意图**：灰色是原配置的样子，高亮是新增内容该放的位置（`...` 表示你原有配置的其它部分）。**不需要替换整段配置。**
3. 登录面板 → 找到这个域名的站点：
   - **反向代理**：目标填 `http://127.0.0.1:云端端口`（之前配过就跳过）。
   - **配置修改**：把复制的几行粘到示意图对应的位置，保存：
     - 密码两行放 `server_name` 下面；
     - 如果开了「只允许指定 IP」，还有 `allow 你的IP;` 和 `deny all;` 几行，也放在同一层；两个都开时密码和 IP 两个条件都要满足；
     - 开着「要密码」时，`auth_basic off;` 放进 `/.well-known/`（证书验证目录）里——这是为了证书到期能自动续，别漏；只开「只允许指定 IP」时没有这一行；
     - 用了「WebSocket」或「大文件上传」预设时，高亮行里会有对应的几行，只能放进已有的 `location / { }` 里，别贴到 server 里。
4. 保存后 **重载 nginx**。
5. 如果弹层里还有 **「密码文件内容」**（像 `用户名:$2y$...` 这样一行）：
   - 密码文件要放在**站点目录**下面。默认（小皮面板）是 `/xp/panel/vhost/你的域名.htpasswd`；面板不是小皮的话，先到「云端服务器」页编辑这台服务器，把「站点目录」改成你面板的目录（比如宝塔填 `/www/server/panel/vhost`），再回来重新生成。没有这个文件就新建一个，一行就够。
   - `$2y$` 后面那串是加密后的密码，不是明文。加密是在你电脑上算好的，服务器上不用装任何额外程序。
   - 「检查云端」找的也是这套路径：站点配置在 `<站点目录>/nginx/你的域名.conf`，密码文件在 `<站点目录>/你的域名.htpasswd`。
6. 贴完别急着关弹层：点弹层里的 **「检查云端」**（或在隧道卡片上点「检查云端」），显示「云端已生效」才算真的配好；对不上就按上面的提示重新贴一次。
   - 检查结果还会顺手看 **HTTPS**：网址写的是 https 但服务器上没开、证书快到期、密码能用 http 明文提交，这些都会用红字或黄字提醒你怎么处理。网址写的是 http、服务器其实支持 https，也会提醒你改成 https。

> 每次改了访问保护（加/减密码、加/减 IP 白名单）、改了云端端口、换了发布预设，都要重新做一遍第 4 步，否则云端还是旧配置。改完点「检查云端」确认生效。

### 第 5 步：访问验证

1. 用电脑浏览器打开 `https://你的域名`，输用户名密码，看到内容 = 成功。
2. 手机关掉 Wi-Fi、用移动网络再开一次（确认公网真的能进）。开了「只允许指定 IP」时，手机不在白名单里进不去是正常的，用白名单里的网络试。
3. 回到应用看状态：
   - 「本机服务」页显示 **在跑**；
   - 「发布隧道」页显示 **正在发布**。

### 卡在哪一步了？

**先去「设置 → 体检」点一下**：它会从程序、文件夹、SSH、本机端口、服务器、隧道、云端配置、公网访问、域名解析一路检查，哪一步没过直接告诉你怎么办。想查得更全，切「深度检查」（会连服务器和公网，最多 1 分钟）。

快速对照：

| 现象 | 先看哪里 |
|---|---|
| 找不到「本机正在监听的端口」 | 程序是不是还没启动？先把它跑起来再回来点 |
| 保存服务器时提示要密码登录 | 服务器不允许密码登录，改用手动配密钥 |
| 发布隧道时提示端口已被占用 | 换一个云端端口再发布 |
| 网址打不开 | 先体检；再看第十章「常见问题」 |

## 三、每个页面、每个字段说明

### 3.1 本机服务页

页面标题「本机服务」，说明：*这台电脑上的程序：记下端口和启动方式，就能帮你启动、看护。* 右上角两个按钮：**「导入现有脚本」**、**「+ 添加本机服务」**。

**列表工具条**（有服务时显示）：搜索框（搜名字、端口）、状态筛选（全部 / 在跑 / 没启动 / 正在启动 / 端口不通 / 起不来）、排序（默认排序 / 按名字 / 按本机端口）、**「批量管理」**按钮。

**批量管理**：进入后每条前面有勾选框，底部出现操作栏：`已选 N 条`、`全选这 M 条`、`启动`、`停止`、`删除`、`取消`。删除会弹确认框；删除后右下角有 5 秒的「撤销」机会（见第六章「撤销删除」）。

**卡片上每样东西：**

| 位置 | 内容 | 意思 |
|---|---|---|
| 最左边圆点 | 彩色圆点 + 状态词 | 状态永远有三样：颜色 + 中文词 + 一句人话 |
| 名字 | 比如 comfyui | 你登记时起的名字 |
| 按钮 | 启动 / 停止 | 只有填了「启动程序」才显示。只监控的服务没有这个按钮。停止时如果端口上不是本应用**这次**启动的进程（包括上次退出后留下、这次被认领的），会先弹确认框，确认后才真的关掉 |
| 「⋯」菜单 | 编辑本机服务 / 看程序日志 / 删除本机服务 | 点开就能操作 |
| 第二行 | 本机端口 · 启动程序 或 只监控，不帮你启动 · 备注 | 一眼看清它是谁 |
| 第三行 | 看护 ☑ / 开机自启 ☑ / 已发布到 N 条隧道 | 两个开关随时可以拨 |
| 日志提示 | 日志太长了，只留了最近一段 | 程序日志超过 5MB 时出现；下次重启这个服务会自动把旧日志轮转归档（保留最近两份），想看旧日志去数据目录的 `logs\` 里找 |
| 修复带 | ⚠ 原因 + 按钮 | 出问题时才出现，最多两个按钮 |

**五个状态词（颜色圆点旁边的字）：**

| 状态词 | 意思 | 你能做什么 |
|---|---|---|
| 在跑 | 程序在跑，端口也通 | 不用管 |
| 正在启动 | 程序已经拉起来，正在看端口通不通，等几秒 | 等几秒 |
| 没启动 | 程序没在跑 | 点「启动」（要填过启动程序） |
| 进程在但端口不通 | 程序还在，但端口一直不通（可能卡死），或者它监听的不是这个端口 | 开着看护：应用会先停掉它再自动重启；没开看护：只报警不动它，自己点「启动」重试，或点「改端口」、看程序日志 |
| 起不来（已停止自动重试） | 程序启动失败，已经停止自动重试 | 点「再试一次」、看日志，检查启动程序/参数/工作目录 |

**添加 / 编辑弹层里的字段：**

| 字段 | 说明 |
|---|---|
| 名字 | 不能为空。点端口列表会自动填 |
| 本机端口 | 要填 1~65535 的数字。同一台电脑上不能有第二个服务用同一个端口 |
| 本机正在监听的端口 | 点一行，自动填「端口 + 启动程序 + 名字」，接着自动读取启动参数和工作目录；填完还能手动改。读不到就先启动程序 |
| 启动程序（可留空 = 只监控不启动） | 留空的话只能看状态，启动、看护、开机自启都用不上 |
| 启动参数（可留空） | 两行文本框；点端口行会自动读取正在跑的那条命令的参数。手填时注意：引号里以反斜杠结尾要写成两个（例 `"D:\data\\"`），否则按 Windows 引号规则，结尾那个 `\` 会把引号转义掉，参数就变形了 |
| 工作目录（可留空） | 程序从哪个文件夹开始跑。自动读取到的是它**现在**的工作目录（程序自己切过目录的话会变） |
| 看护 | 勾上 = 程序掉了自动拉起来；进程还在但端口一直不通（卡死）时也会先停掉再重启。**没填启动程序就不能开**（会弹一句人话拦下来） |
| 开机自启 | 勾上 = 应用启动后帮你跑起来。**没填启动程序就不能开** |
| 备注（可留空） | 给自己看 |

**自动读取启动方式（点端口行之后）**：

- 先照旧把「端口 + 程序 + 名字」填上，然后去读正在跑的那个进程是怎么启动的，把「启动程序 / 启动参数 / 工作目录」补全。
- 自动填过的字段旁边会显示「自动读取 · 未验证」小标签；你一手动改，标签就消失。
- **编辑旧服务时**：如果这几个字段里已经有内容，会先问一句要不要用读到的内容覆盖；点取消就保留你原来的，启动程序/参数/工作目录**三个字段都保持原样**（不会只换掉其中一个）。
- **读到的信息不可靠就不覆盖**：端口被多个进程占用、占用进程已经退出、端口换了主人、进程号对不上——这些情况一个字都不填，只在警告区告诉你原因，你自己决定怎么办。
- **疑似密钥会拦住保存**：参数里像是带了密钥（`--token`、`password=` 这类）会红字提醒，并出现勾选框「我知道这些参数里有疑似密钥，仍然保存」；不勾选，保存按钮点不了。
- **参数没自动填时能看原文**：参数里含换行/制表符或太长时，应用不会把它填进配置，而是在警告区只读显示「读取到的原始命令行」（最多 3 行，可复制），方便你照着改。
- **实际会执行的命令行**：启动参数下面有一行只读小字，显示最终会执行的命令（`.bat` / `.ps1` / `.sh` 会显示实际用 `cmd` / `powershell` / `bash` 包装后的样子），读不到就不显示。

**参数引号小知识**：Windows 传参时，引号里以反斜杠结尾的写法（如 `"D:\data\"`）会把结尾引号转义掉，参数会变形。要让参数以反斜杠结尾，写两个：`"D:\data\\"`。

**已登记端口会跳去编辑**：端口如果已经登记在别的服务名下，那一行会标出「已登记：名字」。点它不会在这里重复登记，而是直接跳到那台服务的编辑界面，并自动读取补全（新建服务时也有这段说明）。

**停止确认（人话版）**：点「停止」时——

- 是应用自己启动的进程：直接停，不啰嗦。
- 是你自己手动开的程序在监听这个端口：应用不会直接动手，会弹确认框告诉你「这台服务不是你启动的，正在监听的是 xxx.exe（PID 1234）。停止会真的把它关掉，确定吗？」。确认才真的关掉，取消就什么都不做。**上次应用退出后留下的进程**下次启动时就算被按端口认领了，停止时也算「不是这次启动的」，同样要先确认。
- **启动程序是包装脚本时**（`.bat` / `.ps1` / `.sh` 等，真正监听端口的是脚本拉起的子进程）：应用会把自己启动的这棵进程树（脚本 + 子进程）一起停掉，所以不会因为是子进程在监听就误弹「这不是你启动的」确认框；已经脱离出去、追不到的进程才会按外部进程弹确认。
- 失败时把原因直接写在卡片上，不弹看不懂的报错。

**导入现有脚本**：点开后有两个页签——

- **旧脚本**：默认会扫 pi-web 的旧启动脚本（`~\.pi\pi-web\start-pi-web.ps1`），读出端口和目标服务器，生成「一台本机服务 + 一条已暂停的隧道」。想扫自己的脚本，退出应用后设一个环境变量 `SHANGXIAN_SCAN_EXTRA`（格式 `名字=完整路径;名字=完整路径`）再打开应用。**导入后隧道是暂停的**，确认新工具跑稳、停掉旧脚本之后，再去「发布隧道」页点「开始发布」完成接管。启动方式不会自动接管，需要到本机服务页补上。
- **配置文件**：从导出的设置文件恢复（见第六章 6.3「导出和导入设置」）。

**删除本机服务**：会弹确认框。如果还有隧道在用它，程序会拦下来并告诉你哪几条隧道，先删隧道再删服务。它不会自动连带删。删除后 10 分钟内可以在设置页「最近删除」里恢复（恢复的是登记信息，不会帮你启动）。

### 3.2 发布隧道页

页面标题「发布隧道」，说明：*把本机服务接到云端；每条都能加访问保护。* 右上角 **「+ 发布新隧道」**。

**列表工具条**：搜索框（搜名字、网址、端口）、筛选（全部 / 正在发布 / 掉线重连中 / 出错 / 已暂停 / 连接中 / 没设保护 / 待核对；最后两个用来一眼找出还没设门禁、或还没核对云端的隧道）、排序（默认排序 / 按名字 / 按云端端口 / 按服务器 / 最近有变化）、**「按服务器分组」**开关、**「批量管理」**按钮。分组后组头显示 `服务器名 · N 条`，掉线时还会标出来，点一下可折叠。

**批量管理**：底部操作栏是 `已选 N 条`、`全选这 M 条`、`开始发布`、`暂停发布`、`删除`、`取消`；删除同样弹确认框、5 秒内可撤销。

**卡片上每样东西：**

| 位置 | 内容 | 意思 |
|---|---|---|
| 圆点 + 状态词 | 见下面的五状态表 | |
| 徽标 | 发布预设 | 只在 WebSocket / 大文件上传时显示 |
| 按钮 | 暂停 / 开始发布 | 暂停后别人就打不开了 |
| 「⋯」菜单 | 编辑隧道 / 克隆这条隧道… / 复制公网网址 / 云端配置（nginx）/ 看发布日志 / 访问保护 / 访问记录 / 删除隧道 | 「复制公网网址」没填网址时点不了；「克隆」会照现有隧道复制一条新的（默认暂停，默认不复用同一个网址） |
| 第二行 | 服务名 → 服务器名 · 云端 端口 · 网址 | 一眼看清从哪到哪 |
| 第三行 | 已连 2 小时 13 分 · 今日重连 3 次；或 第 2 次重试，8 秒后 | 正在发布时显示运行时长；掉线/重连中显示重试倒计时；重试停了会提示「先点『暂停』，再点『开始发布』就能重新试」 |
| 黄色小条 | 本机服务没在跑（访问会失败，先去看本机服务页） | 问题在源头，不在隧道 |
| 保护行 | 访问保护小牌 + 「检查云端」 | 小牌显示当前门禁（没设保护标红，云端核对过才变绿），点一下打开「访问保护」弹层改密码 / 白名单；「检查云端」去云端读实际生效的状态 |
| 漂移条 | 云端和设置对不上：差异列表，重新贴一次云端配置 | 最近一次「检查云端」发现云端和本机设置不一致时出现；可以「打开云端配置」或「暂时不管」 |
| 修复带 | ⚠ 原因 + 「看日志」 | 出问题时才出现；原因是端口被占时按钮会变成「改云端端口」 |

**五个状态词：**

| 状态词 | 意思 | 你能做什么 |
|---|---|---|
| 正在发布 | 隧道连上了。但云端 nginx 还没贴的话，别人照样打不开 | 可以点「暂停」；在卡片上点「检查云端」确认云端真的生效 |
| 连接中 | 正在和云端服务器建立连接，几秒钟就好。一直停在这里多半是连不上 | 等几秒；还不行点「看日志」 |
| 掉线重连中 | 云端服务器联系不上了，可能网络波动。会自动重试 | 等自动重试；实在不想等，就点「暂停」，再点「开始发布」|
| 出错 | 发布失败。卡片上会写出具体原因（比如登录被拒、地址解析不了） | 修好原因后点「暂停」，再点「开始发布」；也可以看日志 |
| 已暂停 | 你暂停了发布，现在没人能访问 | 点「开始发布」 |

**新建隧道向导（3 步）：**

| 步骤 | 字段 | 说明 |
|---|---|---|
| 第 1 步 | 选一台本机服务 | 只会发布你选中的这台；一台都没有时能直接去添加并回到向导 |
| 第 2 步 | 云端服务器 | 下拉选一台；一台都没有时能直接去添加 |
| 第 2 步 | 云端端口 | 已经帮你挑了一个没人用的（从 13000 开始）。被别的隧道占了会直接说明、下一步点不了 |
| 第 2 步 | 别人访问时用的网址（可留空） | 填了要去域名商加 A 记录 |
| 第 2 步 | 发布预设 | 普通网站（默认）/ WebSocket（实时通信）/ 大文件上传 |
| 第 3 步 | 访问保护两个开关 | 要密码（默认开，推荐）/ 只允许指定 IP；两个可以同时开，两个都不开 = 谁都能进 |
| 第 3 步 | 访问用户名、密码、换一个 | 默认用户名 `shangxian`，密码自动生成 16 位 |
| 第 3 步 | 给这条隧道起个名字 | 默认是「服务名 发布」，只有你自己看得到 |
| 第 3 步 | 两个保护都不开时 | 会多出一个「我知道了，这样发布（不推荐）」的勾选框，**不勾不给发布** |

保存后是成功屏「**隧道建好了，还差最后一步**」：网址和密码（密码只显示这一次）在这里显示；有网址时能显示二维码；点「**下一步：贴云端配置**」直接打开云端配置弹层，或者点「稍后再说」。没填公网网址也能建，但成功屏会提醒你：这条隧道还没有对外地址，别人暂时打不开，回头到「发布隧道」页编辑就能补。

**编辑隧道弹层**（隧道卡片 ⋯ →「编辑隧道」；只改发布相关的东西）：

| 字段 | 说明 |
|---|---|
| 隧道名字 | 不能为空 |
| 公网网址（可空） | 你的域名 |
| 云端端口 | 改了保存后会断开重连一次 |
| 发布预设 | 改了以后要重新贴一次云端配置 |

弹层里没有访问保护：保存时保护设置原样保留，改名字/网址/端口/预设不会误动密码或 IP 白名单。要改保护，点卡片上的保护小牌（或 ⋯ 菜单「访问保护」）。

**克隆隧道**：从卡片 ⋯ 里选「克隆这条隧道…」。新名字默认是「源名 的副本」，服务器和预设沿用原来的，网址默认留空（一个网址只能给一条隧道用），保护设置想留就留、想改就改。克隆出来是暂停状态，检查好了再点「开始发布」。

改了**云端服务器自己的参数**（地址、SSH 端口、账号、密钥）也不用重建隧道：应用发现正在跑的隧道参数变旧了，会自动停掉旧的、按新参数重新连（包括改了本机服务的端口也一样）。连不上的人话原因会写在卡片上。

**怎么核对云端实际生效的保护（「检查云端」按钮）：**

1. 应用里显示的「当前设置的保护」只是你希望的状态；云端真的有没有生效，在隧道卡片上点「检查云端」（「云端配置」弹层里也有同一个按钮）。
2. 应用会 SSH 到云端，读这个域名的站点配置和密码文件（站点配置在 `<站点目录>/nginx/<域名>.conf`，密码文件在 `<站点目录>/<域名>.htpasswd`；站点目录见 3.3），然后告诉你：要不要密码（开/关）、IP 白名单（开/关、里面有几个 IP）、密码文件在不在；顺带看 HTTPS 和云端端口回环。
3. 显示的和应用里设置的对不上（常见：贴了片段没重载、换了密码没重贴、白名单忘了改），按提示重新走一遍第 4 步，把新片段贴到面板里，再点一次「检查云端」确认。
4. 检查结果会记下来：改了保护相关设置（密码 / 白名单 / 站点目录等）后，核对结果会自动清成「待核对」，需要再点一次「检查云端」；上次核对超过 24 小时也会重新标「待核对」。多留意一下就永远不会拿旧结果骗自己。

### 3.3 云端服务器页

页面标题「云端服务器」，说明：*一台一直开着的电脑，负责把别人的访问转给你的电脑。* 右上角 **「+ 添加服务器」**。

**卡片上：** 名字、`登录账号@地址:端口`、`密钥 路径` 或 `默认密钥`、`站点目录`；三个按钮「测试连接」「编辑」「删除」。

**「测试连接」**：真去 SSH 连一次这台服务器（最长等 15 秒），成功显示「连接成功，用时 x.x 秒」；失败直接说人话（超时、登录被拒、地址解析不了、密钥路径不对等）。配置改完先点一下，比等发布失败再查省事。

**添加 / 编辑弹层字段：**

| 字段 | 说明 |
|---|---|
| 名字 | 自己好认就行 |
| 服务器地址 | IP 或域名 |
| 登录账号 | SSH 用户名 |
| SSH 端口 | 默认 22 |
| 密钥文件（可留空） | 留空就用系统默认密钥（`~/.ssh` 里那把） |
| 站点目录（可留空） | 面板把网站放在服务器哪个目录。留空就按小皮面板默认 `/xp/panel/vhost` 找；宝塔等面板填 `/www/server/panel/vhost`。生成云端配置、放密码文件、「检查云端」都按这个目录算。不确定就先留空 |

**「没有密钥？」区域（重要，第一次用很方便）：**

- 添加 / 编辑弹层里都有 **「用密码登录一次，帮我配好免密」** 按钮。输入服务器的登录密码，程序会：
  1. 生成一把专属密钥；
  2. 用密码登录一次；
  3. 把公钥写到服务器上；
  4. 立刻用密钥验证一次。
- 如果是还没保存过的新服务器，助手会**先自动把服务器保存下来**，再开始配（不用你先手动存一遍）。
- 成功后密钥存在「数据目录」里（一般是 `%APPDATA%\Shangxian\keys\` 或 `%LOCALAPPDATA%\Shangxian\keys\`；以「设置」页点「打开」看到的为准），以后这台服务器都走密钥，不再用密码。
- 密码只在内存里用一次，不会存下来。

**删除服务器**：如果还有隧道挂在这台服务器上，程序会拒绝，提示「还有隧道挂在这台服务器上，先处理它们」。先删隧道，再删服务器。删除后 10 分钟内可以在设置页「最近删除」里恢复。

### 3.4 访问保护（在「发布隧道」页的卡片上）

访问保护没有单独的页面：每条隧道的门禁就在它的卡片上，和发布状态在同一张卡里。

- 卡片上的**保护小牌**显示当前门禁（没设保护标红，云端核对过才变绿）；**点小牌**（或卡片 ⋯ 菜单 →「访问保护」）打开「访问保护」弹层改设置；旁边**「检查云端」**去云端读实际生效的状态。
- 列表工具条的 **「没设保护」「待核对」** 两个筛选（各带条数）：点一下只看还没设门禁、或还没核对云端的隧道——这就是旧「访问保护」页一览的替代。
- **绿色只在「检查云端」确认对得上之后才出现**：贴了配置但没重载、云端还是旧密码，都算「还没生效」。上次核对超过 24 小时也会重新标「待核对」（核对只手动做）。
- 检查云端发现云端和设置不一致时，卡片上会出现漂移条，写明差在哪（云端没找到站点配置 / 密码开关不一样 / 白名单开关不一样 / 白名单里的 IP 不一样 / 服务器上还没有密码文件），点「打开云端配置」去修。

**保护弹层里的字段**（从卡片保护小牌或 ⋯ 菜单打开）：

| 字段 | 说明 |
|---|---|
| 要密码才能进（推荐） | 打开 = 别人打开网页要先输用户名和密码 |
| 访问用户名 | 打开「要密码」时显示，默认 `shangxian`，可以改 |
| 新密码 | 打开「要密码」时显示。**留空 = 沿用原来的密码**；填了就用新的 |
| 只允许指定 IP 访问 | 打开 = 只有你写的 IP 能进，在下面填，逗号分隔，比如 `1.2.3.4, 5.6.7.8` |
| 查公网 IP | 在 IP 白名单输入框下面：查到后点「加进白名单」即可；保存时如果你没把自己加进去，会先弹确认框拦一下 |
| 两个都不开 | ⚠ 弹层里会标红提醒：谁知道网址谁都能进 |

- **保存成功后会自动打开这条隧道的「云端配置」**：把新的几行贴到服务器面板里并重载 nginx，保护才算真的生效（这是设计好的下一步，别跳过）。
- 密码不存本地，只存加密结果，找不回原文；忘了就在这个弹层里填一条新密码保存。
- 提示：家里宽带的 IP 会变，变了以后白名单会把自己挡在外面，到时来这里把新 IP 加进去。手机流量、公司网络、运营商共享 IP 下白名单可能不生效，改用密码更省心。

**保护小牌对照：**

| 小牌 | 意思 | 点开后改什么 |
|---|---|---|
| 要密码（用户名 xxx） | 已经设好密码 | 改密码 |
| 选了要密码，但还没设 | 缺密码，别人现在进不来也不安全 | 改密码 |
| 仅白名单 IP（N 个） | 白名单里有 N 个 IP，只有它们能进 | 改白名单 |
| 仅白名单 IP（还没填 IP） | 开了白名单但一个 IP 都没填，别人进不来 | 改白名单 |
| 密码 + IP 白名单 | 两个都开了，两个条件都要满足 | 改保护 |
| 密码 + IP 白名单（还没设密码） | 白名单有了，密码还没设 | 改保护 |
| 无访问保护 | 没有任何保护 | 加保护 |

- 卡片上的小牌（比如「要密码（用户名 xxx）」）表示**本地的设置**；没点过「检查云端」之前，小牌后面带「· 待核对」，颜色也不会变绿。想看/复制云端配置，在卡片 ⋯ 菜单里点「云端配置（nginx）」；改完保护保存后它会自动打开。
- 弹层里提醒：*这里的密码是别人打开网页时输的；连服务器用的登录密码在「云端服务器」页。密码不会存在本地（只存加密结果），忘了就重新设一个；保存成功后直接打开的云端配置里，记得把新片段贴到面板里，再点「检查云端」确认真的生效了。*

**访问记录**：卡片 ⋯ 菜单里点「访问记录」会弹出窗口，助手会去读云端访问日志的最近 1000 行，告诉你：密码错误被挡了多少次、白名单被挡了多少次、哪些 IP 试得最多，以及最近几条被挡的原始记录。

- 次数是**大概数**（按日志格式估算），仅供参考。
- 日志格式特殊、只有 root 能读、没找到日志时，会直接说「这一步跳过」，不瞎编。
- **这些记录只在你自己电脑上显示，不会上传到任何地方。**
- 访问记录只在你点的时候才读一次，不会定时去翻你的访问日志。

### 3.5 设置页

| 项目 | 说明 |
|---|---|
| 外观 | 跟随系统 / 浅色 / 深色 三选一 |
| 开机自动启动 | 登录电脑后自动在托盘里运行，不弹窗口。开 / 取消 |
| 掉线提醒 | 隧道或服务出问题超过 3 分钟、或恢复时，弹一条系统通知。可以点「发一条测试通知」看通知长什么样，也可以关掉 |
| 刷新频率 | 界面多久看一次状态：500 毫秒（最灵敏，费一点电）/ 800 毫秒（默认）/ 1000 毫秒 / 2000 毫秒（2 秒，省电）/ 5000 毫秒（5 秒，最省电）。只影响界面刷新，不影响后台看护；切到别的窗口时界面会暂停刷新，回来立刻刷新 |
| 启动时自动检查更新 | 打开后，启动约 30 秒会去发布页看一眼有没有新版本（6 小时内不重复查）；只提示，不自动下载安装。关掉就永不自动查，需要时到「关于」里手动点「检查更新」 |
| 免打扰时段 | 默认关；打开后默认 22:00 到 08:00。这段时间里通知照记在通知中心，但不弹系统提醒；**只压「掉线」提醒，「恢复」照报**（免得你以为还坏着）。开始和结束时间一样，等于没设 |
| 数据目录 | 显示数据目录路径和来源（便携模式 / 环境变量指定 / 本机应用数据 / 漫游应用数据），点「打开」直接在资源管理器里打开。配置、日志、密钥都在这里；搬家时整个文件夹拷走就行 |
| 最近删除 | 删除后的 10 分钟内可以在这里恢复隧道 / 本机服务 / 服务器，显示剩余时间，能单条或全部恢复；隧道恢复后是暂停状态，服务恢复后不会自动启动 |
| 体检 | 「开始体检」打开体检弹层（见第四章） |
| 关于 | 版本号、数据目录、SSH 可用性（体检后显示）、后台守卫、配置状态、检查更新、导出诊断包 |

**关于卡片上的「检查更新」**：

- 还没检查过 → `还没检查过`，点「检查更新」去查；
- 已是最新 → `已是最新版本（v0.6.0）`；
- 有新版本 → `有新版本 x.y.z，当前是 v0.6.0` + **「去下载」**按钮，点开的是本项目的发布页（`github.com/iranolly/shangxian/releases`）；
- 检查失败 → 写人话原因（比如网络连不上），点「再试一次」。
- 启动时自动检查发现新版本时，只会提醒**一次**（同一个版本不重复弹），绝不会下载或安装。

### 3.6 通知中心

标题栏右侧有一个**铃铛**图标，有未读时上面有小数字。

- 点开是通知列表，按「今天 / 昨天 / 更早」分组；掉线、恢复、新版本、体检失败这些事都记在这里，能回看。
- 右上角 **「全部标为已读」**；点某条通知会跳到对应的隧道 / 服务并高亮（那条已经不在了会提示你）。
- 右上角还有 **「界面静音 1 小时」**：点一下，这 1 小时里不弹应用内的小提示条，铃铛上的未读数也先不冒出来；通知一条不少，照旧记在列表里。再点一次 **「取消界面静音」** 立刻恢复。它只管应用界面——要压 Windows 系统通知，还是用设置页的「掉线提醒」总开关或「免打扰时段」。
- 底部有 **「免打扰设置」**，点一下跳到设置页的免打扰时段。
- 空的时候显示「还没有通知」。通知框能收到的是「应用里发生的事」；系统级的弹窗还受设置页「掉线提醒」和「免打扰时段」控制。

### 3.7 几个弹层

**日志查看器**（隧道卡片 ⋯ → 看发布日志；本机服务卡片 ⋯ → 看程序日志；也可以在日志里点「全部日志」）：

- 顶部工具条：搜索框（搜日志里的字…，带上一个 / 下一个）、过滤（**全部 / 只看人话行 / 只看错误**）、显示行数（**200 / 500 / 1000 / 2000，默认 500**）、自动刷新开关、复制全部、导出文件…、归档（**当前日志 / 上一份 / 上上份**）、显示路径 + 打开文件夹；不是全部日志时还有「全部日志」按钮。
- 列表每行格式：`[时:分:秒] [来源] 内容`；来源显示「应用 / 发布:名字 / 程序:名字」。
- **全部日志**：把所有隧道和程序的日志合在一起，**按来源分组**（不做全局时间排序），一眼看清谁在什么时候说了什么。
- 新版「发布日志」= 这条隧道和云端服务器的连接记录；「程序日志」= 程序自己打印的内容，还有看护记录（启动、退出、自动重启、假死重启等）。
- 你往上翻时会自动暂停刷新，点「回到最新」恢复；日志太多只显示一部分时会提示。
- **「导出文件…」**把当前看到的内容存成文件，位置在数据目录的 `exports\` 文件夹里，存好会弹出路径。
- 日志文件按隧道/服务的 **id** 命名（不是按名字），改名不会换日志文件；隧道日志超过 5MB 会自动轮转，只留最近两份备份（`.1`、`.2`）；程序日志超过 5MB 也是下次启动时轮转，保留两份。更早的可以到数据目录的 `logs\` 文件夹里翻。
- 出问题时把它复制出来，定位问题最快。空的时候先点「体检」查一下。

**访问保护**（从隧道卡片的保护小牌或 ⋯ 菜单打开）：改网页访问密码 / 访问用户名 / IP 白名单。密码留空 = 不换；保存成功后自动打开这条隧道的「云端配置」，接着去贴片段。

**云端配置（nginx）**：显示使用步骤、nginx 片段（可复制，按段给复制按钮）、证书续期要加的行、可选附加行（告诉搜索引擎别收录）、密码文件内容（如果设了访问保护）。最上面有「检查云端」按钮，显示云端实际状态和 HTTPS 提醒。

**导入**（“导入现有脚本”按钮）：两个页签，**旧脚本**（扫描 pi-web 等旧启动脚本）和**配置文件**（恢复设置，支持先检查后导入）。

**体检弹层**：见第四章。

**导出诊断包**：一个「深度检查」勾选项（默认不勾，只查本机；勾上会连服务器和公网，最多 1 分钟）。点「导出诊断包」后存到数据目录的 `diag\` 文件夹，弹出路径。包里会放：应用版本、系统信息、脱敏后的设置、隧道和服务的状态、最近的日志、体检结果；**不会放**登录密码、密码加密结果、私钥内容、控制令牌、启动参数原文。包只存在本机，不会自动上传。

**二维码**：隧道成功屏或需扫码时出现，白底黑码，尺寸够大；二维码是离线生成的，不会把网址发到网上。网址太长扫不出来时，用旁边的复制按钮。

## 四、出问题怎么办：体检、日志、诊断包

### 4.1 先用体检

**入口**：「设置」页 → 「体检」→「开始体检」。

- **快速检查**（默认）：不连服务器、不连公网，几秒钟出结果，查本机和配置。
- **深度检查**：会连服务器和公网，最多 1 分钟；提示「深度检查会连服务器和公网，最多 1 分钟。」

**体检的 9 步**（顺序固定）：

| 步骤 | 查什么 |
|---|---|
| 1 程序状态 | 应用在不在跑、配置能不能读 |
| 2 文件夹 | 数据目录在不在、能不能写、有没有读坏的配置留底 |
| 3 SSH 程序 | 系统自带的 ssh 找不找得到 |
| 4 本机端口 | 已登记的服务端口通不通 |
| 5 云端服务器 | 用到的服务器信息全不全、密钥文件在不在 |
| 6 发布隧道 | 开启的隧道引用对不对、有没有出错 |
| 7 云端配置 | （深度）连服务器看能不能登录、站点目录在不在 |
| 8 公网访问 | （深度）从本机连一下云端端口 |
| 9 域名解析 | （深度）网址的域名能不能解析出 IP |

**结果怎么看**：

| 状态 | 意思 |
|---|---|
| ✓ 通过 | 这一步正常 |
| ! 要留意 | 能跑，但建议看一眼 |
| ✕ 没通过 | 出问题了，弹层会自动展开第一处失败的「怎么办」 |
| – 跳过 | 这次没查（比如快速检查不连服务器），或者没有可查的对象 |

- 顶部有汇总条：全过是绿条「体检全过了」；有失败是红条「有 N 项没通过」；只有跳过是黄条，提示你切「深度检查」再跑一次。
- 底部按钮：**再体检一次**、**复制体检结果**（复制出来发给懂行的人）、**导出诊断包**、**关闭**。
- 命令行的同款功能：`cli doctor`（加 `--deep` 深度，`--strict` 有没过就退出码 1）。应用没在跑时，`cli doctor` 也能查本机、文件夹、SSH 和配置。

### 4.2 日志怎么看

1. 先点对应对象的「⋯」→「看发布日志 / 看程序日志」。
2. 默认看最近 500 行；想多看就在「显示行数」里调到 1000 / 2000。
3. 出错了先切 **「只看错误」**；想找关键词就用搜索框。
4. 贴配置前后对比、看时间线时，把 **「自动刷新」** 开着；往上翻会自动暂停。
5. 发给别人时点 **「复制全部」** 或 **「导出文件…」**。
6. 想看全部来源就点 **「全部日志」**（按来源分组）。

### 4.3 诊断包什么时候用

当你自己按体检的提示也修不好、需要找懂行的人帮忙时：设置页 → 关于 → **「导出诊断包」**，勾上「深度检查」（如果对方需要），把生成的 zip 发过去。

- 包里**没有**密码、密码哈希、私钥、控制令牌、启动参数原文。
- 包存在本机，不会自动上传。
- 深检的包会带连服务器和公网的结果；快速包只带本机信息。

## 五、通知、免打扰、睡眠唤醒和崩溃恢复

### 5.1 通知都什么时候来

- **掉线**：隧道连不上超过 3 分钟，弹一条；同一条 30 分钟才会再提醒一次；多条一起出问题会合并成一条。
- **恢复**：重新连上时弹一条。
- 服务只要开了看护或开机自启，也在提醒范围内；你自己手动停掉的不报。
- 通知的内容也会记进标题栏的「通知中心」，没弹出来的（比如免打扰时段）也能回看。
- 点击系统通知会打开应用（通知从屏幕上消失进了「操作中心」后，Windows 不再上报点击；所以托盘图标是更稳的入口）。
- 系统通知发不出去（比如你关了系统通知权限）时，应用会记一条并提示你；掉线和恢复仍然记在通知中心。
- 想验证通知长什么样：设置页「掉线提醒」旁边点「发一条测试通知」。

### 5.2 免打扰时段

- 位置：**设置页 → 免打扰时段**。默认**关闭**，开始 22:00、结束 08:00。
- 打开后，这段时间里**掉线提醒不弹系统通知**（仍然记进通知中心），**恢复提醒照弹**。
- 开始和结束时间相同 = 没设免打扰。
- 「掉线提醒」总开关关掉 = 所有掉线/恢复通知都不弹（也会记在应用日志里）。
- 只嫌应用里的小提示条吵、又不想动系统通知？用通知中心右上角的「界面静音 1 小时」（见 3.6），两者互不影响。

### 5.3 睡眠唤醒 / 网络恢复会自己接上

- 电脑睡醒后，正在发布的隧道会**立刻全部重新连**，不用等你手动点；正在等的重试会提前。
- 换 Wi-Fi、插网线、VPN 起落之后，正在等待重连的隧道会马上再试一次；已经连得好好的一般不打扰。
- 睡醒或换网时，界面会给你一条一次性提示；一般几十秒内就能回到「正在发布」。

### 5.4 程序崩溃会自动恢复

- 应用意外崩溃时，Windows 会把「上线助手」静默拉回托盘继续看护（不会自己弹窗、不会打断你）；本机服务一直没受影响。
- **防死循环**：10 分钟内连续崩溃 3 次，会自动暂停恢复并弹一条提示（免得崩了起、起了崩）。这时手动重新打开一次应用，就会重新登记自动恢复；10 分钟窗口过了计数也清零。
- 任务管理器里强杀进程、托盘正常退出、系统关机**不会**触发这种自动恢复，这是 Windows 的规则；下次登录时「开机自动启动」会兜底。
- 想看崩在哪，去数据目录的 `logs\app.log`（设置页「数据目录 → 打开」）。

## 六、数据、备份、搬家和撤销

### 6.1 数据放在哪

所有东西都在一个文件夹里（叫「数据目录」）。找法：**设置页 → 数据目录**，路径旁边点「打开」；设置页还会写清它是哪种来源：

| 来源 | 什么时候用 |
|---|---|
| 便携模式 | 程序旁边有 `shangxian.portable` 标记（便携版），数据放在程序旁的 `data\` 里 |
| 环境变量指定 | 设过 `SHANGXIAN_DATA_DIR`（必须是完整路径） |
| 漫游应用数据 | 老安装：`%APPDATA%\Shangxian`（`C:\Users\你的用户名\AppData\Roaming\Shangxian`），存在就继续用 |
| 本机应用数据 | 新安装：`%LOCALAPPDATA%\Shangxian`（`C:\Users\你的用户名\AppData\Local\Shangxian`） |

规则：便携标记 > 老目录（已存在就继续用）> `LOCALAPPDATA` > `APPDATA`。两个环境变量都没有时会直接报错，不会悄悄把东西放到相对目录里。

| 文件/文件夹 | 里面是什么 | 能删吗 |
|---|---|---|
| `config.json` | 全部配置：服务器、本机服务、隧道、开关（当前格式版本 6） | 删了等于全部重配 |
| `config.json.v5.bak` / `.v4.bak` / `.v3.bak` | 老版本升级时自动留的备份 | 可以删 |
| `config.json.bak-<时间>` | 导入配置 / 恢复删除前的即时备份 | 可以删 |
| `config.json.bad` | 配置读坏时的原文件留底（应用不会用空配置覆盖，也不会自动保存；先修好或恢复它才算完） | 修好配置、确认不要了就删 |
| `state.json` | 运行状态：重连次数、保护核对、撤销墓碑等（机器私有，可整份删除）；读坏会留底 `state.json.bad` | 可以删，删了只是统计和保护核对记录清零 |
| `events.jsonl` | 结构化事件流：掉线、恢复、体检、更新等事件；超过 2MB 自动轮转 | 可以删 |
| `keys\` | 每台服务器一把专属密钥（配免密时生成）；里面还有一份 `shangxian_known_hosts`（服务器指纹记录，服务器重装后「重置指纹」会动它） | 删了要重新配免密 |
| `logs\` | 日志：隧道日志 `<隧道id>-<8位代码>.ssh.log`，程序日志 `service-<服务id>.log`，应用日志 `app.log`，体检结果 `doctor-last.json` | 可以删。应用自己写的会重新建文件 |
| `diag\` | 导出的诊断包 | 可以删 |
| `exports\` | 从日志弹层导出的文本文件 | 可以删 |
| `recovery.json` | 崩溃自动恢复的计数记录 | 可以删 |
| `window-state.json` | 窗口位置、大小和最大化状态（下次打开还在原地） | 可以删，删了窗口回到默认位置 |
| `crash-recovery.off` | 崩溃自动恢复的「关」标记（一般不存在） | 不要手删，除非你懂 |
| `ctl.json` | 应用运行时给命令行工具用的「通行证」 | 应用退出后自动失效，不用管 |

> 日志文件按隧道/服务的 **id** 命名（不是名字），所以改名不会换文件；以前按名字命名的旧日志应用不再读，想看就自己去 `logs\` 里翻开。
>
> `config.json` 能手改（改之前先复制一份）。但**手改前先把应用退出**（托盘右键 → 退出），改完再打开应用，免得被覆盖。
>
> **配置读坏了会怎样**：应用不会默默清空你的配置。它会把原文件留底为 `config.json.bad`，界面上弹一条红色提醒说明原因，并且**在读坏期间不自动保存任何新配置**（免得拿空配置把你的东西盖掉）。按红条的提示把 `config.json` 修好（或者用备份恢复）再重开应用。
>
> **装回旧版打不开？** 新版（0.6.0）存的设置，旧版（0.5.x）只认到旧格式。旧版会用只读模式打开：不改你的文件、不自动保存、红条提示你升级，升级回来就自动恢复，不用重新配。

### 6.2 撤销删除（最近删除）

- 删除隧道 / 本机服务 / 服务器后，右下角会弹「已删除「名字」」+「撤销」，**5 秒内点一下就能找回来**。
- 错过了也没关系：**设置页 → 最近删除**，删除后 **10 分钟内**都能恢复，显示剩余时间；一次删了好几条可以「全部恢复」。
- 最多保留最近 **20 条**删除记录，超过的自动丢最旧的；10 分钟一过就彻底删了。
- 恢复的语义：隧道一律回到**暂停**状态（想继续发布再点「开始发布」）；本机服务只恢复登记信息，**不会自动启动**；服务器原样恢复。
- 依赖不在了（比如恢复隧道时它的服务器已经删了）会拒绝，并告诉你是谁不在了。

### 6.3 导出和导入设置

**导出（命令行）**：

```bash
cli config export --out 备份.json     # 默认脱敏：不含密码哈希、不含密钥路径
cli config export --with-paths        # 连密钥路径一起导出（仍然不含密码哈希）
```

- 脱敏导出再导回来，密码哈希和密钥路径会**保留原值**（不会被清空）。
- 不写 `--out` 就把整段 JSON 打印出来，自己存成 `.json` 文件就是备份。

**导入（界面）**：「本机服务」页 → 「导入现有脚本」→ **配置文件** 页签：选一个导出的 `.json` 文件，或者把内容整段粘进去。

- **合并（推荐）**：按 id 对上的对象只改文件里出现的字段，其它保持不动。
- **整体替换**：导入文件里有什么就是什么；助手会先自动备份现在的配置（备份路径会显示出来）。
- 可以点 **「先检查一下」** 做一次干跑：显示会新增几条、更新几条、没变化几条，有问题会列出来；确认没问题再点「开始导入 / 整体替换」。
- 导入会改设置，界面上会弹确认框（整体替换还会再弹一次确认）；替换前自动备份可用。

**导入（命令行）**：

```bash
cli config import 备份.json --dry-run            # 只看会改什么，不写盘
cli config import 备份.json --yes                # 合并导入
cli config import 备份.json --mode replace --yes # 整体替换（导入前自动备份）
```

### 6.4 怎么备份

1. 托盘右键 → **退出**（注意：退出后别人就打不开你的服务了）。
2. 在「设置」页点「数据目录」的「打开」，把整个文件夹复制到 U 盘或网盘。
3. 重新打开应用。

### 6.5 怎么搬家 / 换电脑

1. 新电脑先装好上线助手（见第八章）。
2. 打开一次应用，再退出（让它建好文件夹）。
3. 把备份的 `Shangxian` 文件夹复制过去，覆盖新的。便携版更简单：整个文件夹拷过去就行。
4. 打开应用，重点检查两处：
   - 「云端服务器」页：密钥路径是完整路径，新电脑用户名不一样就可能失效。失效就点「用密码登录一次，帮我配好免密」重新配一次。
   - 「发布隧道」页：确认云端端口和网址没和别的电脑撞。

## 七、开机自启和托盘

### 7.1 托盘是什么

就是电脑右下角（时钟旁边）那一排小图标。上线助手平时就住在这里。

| 操作 | 结果 |
|---|---|
| 点窗口右上角的关闭按钮 ✕ | **只是把窗口收到托盘里，程序不退出**，隧道继续跑。第一次这样做会弹一条系统通知告诉你「已经缩到托盘、怎么找回、怎么真正退出」（只提醒一次） |
| 左键点托盘图标 | 打开主界面 |
| 鼠标悬停在托盘图标上 | 小提示写着「X 条发布中 · Y 条掉线」（没发布时就是「上线助手」） |
| 右键点托盘图标 | 菜单：「打开主界面」「退出并停止全部本地服务」「退出（会停止发布）」 |
| 点「退出（会停止发布）」 | **只退应用**：SSH 隧道立刻停（别人暂时打不开），但**本机服务继续跑**（保活）。正在发布时先弹一个确认框（「现在有 N 条隧道开着发布……确定要退出吗？」），默认选「否」，免得手滑断网 |
| 点「退出并停止全部本地服务」 | 先停**本应用自己启动**的本机服务（连着它拉起的整棵进程树），再停**能核对出是这台服务配置的程序**的认领进程，然后退出；核对不过的（比如启动程序填的是 .bat/.cmd 脚本、实际监听端口的是它拉起的子进程）不会硬杀，会保留并弹一条通知告诉你几个没停。适合想一次性收干净的时候 |

> 记住一句话：**窗口关了没事，托盘退了隧道才断；本机服务默认保活，不会被带走。**

### 7.2 退出和重启应用时，本机服务会继续跑

本机服务的默认行为是**保活**：应用退出、重启、甚至崩溃或被任务管理器强杀，你电脑上那些本地程序都不会被带走，继续在后台跑。

- **为什么不一起关**：你的程序可能还在给别的用途服务（比如自己本地开发、别的工具在用），不该因为关了助手就被连坐。
- **下次打开会「按端口认领」**：应用探测到端口已经在监听（认领只看端口，不核对是不是你登记的那个程序；核对归属只在停止、杀进程时做），就认成「在跑」，不会再拉一个重复的进程去抢端口。
- **崩溃/强杀也不会清理**：应用没来得及善后时，残留的本机服务不会自动消失。想停掉它们：
  - 正常情况：重新打开应用 → 「本机服务」页 → 点「停止」；
  - 实在打不开应用：用任务管理器结束那几个程序。
- **一键退出并全部停掉**：托盘右键 → 「退出并停止全部本地服务」。它会先把本应用自己启动的本机服务停掉，再停能按程序路径核对出归属的认领进程，然后退出应用；核对不过的绝不硬杀（免得误杀）。退出前会弹一条通知：停掉了几个、有几个没能停（没能停的通常需要手动处理）。
- **编辑启动方式不会杀旧进程**：编辑一台正在跑的服务，保存时如果改了启动程序/参数/工作目录，旧程序**保持不动**，卡片上会提示「启动方式已改；正在跑的程序没有动，改动会在下次重启服务时生效」。点「停止」再「启动」才用得上新配置。
- **停止认领来的进程会先问一句**：如果端口上的程序不是本应用这次启动的（比如上次应用退出后留下的），点「停止」会先弹确认框（写着程序名和 PID），确认后才真的关掉（只关端口上这一个监听进程，不会连它拉起的子进程一起结束）。
- **启动程序填成脚本的，停不掉**：如果「启动程序」填的是 .bat/.cmd/.ps1 这类包装脚本，实际监听端口的是脚本拉起的子进程，核对（要求程序路径与配置一致）过不了，界面「停止」和托盘「退出并停止全部本地服务」都不会硬杀它。想让助手能停，把启动程序改成实际监听者的 exe（比如 node.exe、python.exe）。
- **认领只在应用启动后的第一轮探测做一次**：应用启动时服务正好在重启、端口还没起来，这次就认不到；之后不会自动补认，手动点一次「启动」即可。
- **SSH 隧道不受影响**：隧道跟着应用走，应用一退隧道就断（没有保活）；下次打开应用会按原配置重新连上。

### 7.3 设置开机自启

两种自启，别搞混：

| 在哪里开 | 管的是谁 | 效果 |
|---|---|---|
| 「设置」页 → 开机自动启动 | 上线助手自己 | 登录电脑后，应用静默进托盘（不弹窗口），开始看护所有隧道 |
| 「本机服务」页卡片上的「开机自启」开关 | 某个本机程序 | 应用启动后，帮你把这个程序也拉起来（**必须填过启动程序**，没填的话开关会被拦下、开不了） |

想让服务一直在线，推荐：**「设置 → 开机自动启动」打开 + 需要的程序也勾上「开机自启」+ 电脑不关机**。

> **开机自启的「先看后拉」**：应用启动后不是马上拉起所有自启服务，而是先花大约 13 秒看一看——端口已经在听的（上次退出留下的进程）直接认领，不重复启动；还没在听的才拉。这样既不会两个进程抢一个端口，也能快点把服务接上。

> 应用的开机自启不需要管理员权限，它只是登记在你自己账号的启动项里（注册表 HKCU Run，项目名 `Shangxian`）。安装器升级时会帮你保留这个自启项。

## 八、安装、升级、卸载、便携版

### 8.1 新电脑需要什么

| 要求 | 怎么确认 |
|---|---|
| Windows 10 / 11（64 位） | |
| 开启「OpenSSH 客户端」 | 设置 → 系统 → 可选功能 → 添加功能 → 勾「OpenSSH 客户端」 |
| WebView2（界面组件） | Win11 一般自带；Win10 去微软官网下「WebView2 Evergreen 安装包」装上。安装程序也会尝试自动下载安装（需要联网） |

### 8.2 下载

打开项目的 **Releases** 页面（README 里有链接）：

https://github.com/iranolly/shangxian/releases

| 文件 | 说明 |
|---|---|
| `Shangxian_0.6.0_x64-setup.exe` | 安装版（推荐）：装完应用和 `cli.exe` 在一起，开始菜单和桌面有「上线助手」快捷方式 |
| `shangxian-v0.6.0-portable.zip` | 便携版：解压到任意文件夹就能用，不用安装 |
| `SHA256SUMS` | 校验和，用来确认下载完整、没被换过。在下载目录打开 Git Bash，跑 `sha256sum -c SHA256SUMS`；PowerShell 里用 `Get-FileHash .\文件名 -Algorithm SHA256` 后对照即可 |

> 安装包没有代码签名，Windows 可能提示「未知发布者」——点「更多信息」→「仍要运行」即可。校验和只保证「下载完整」，不防钓鱼、不防被人恶意替换，请只从本仓库 Releases 下载。

### 8.3 安装（中文安装器）

1. 双击 `Shangxian_0.6.0_x64-setup.exe`。
2. 安装向导全中文：欢迎页 → 选安装位置（默认装在你自己账号的目录里，**不需要管理员权限**）→ 正在安装 → 完成。
3. 结束页有两个默认勾上的选项：「现在就打开 上线助手」和「在桌面上放一个快捷方式」。不想马上打开就取消勾选。
4. 如果电脑缺「网页显示组件」(WebView2)，安装器会联网自动下载安装（会有「正在下载 / 正在安装」的中文提示）；装不上会告诉你去微软官网下载安装包，装好后重新运行本安装包。
5. 装完在开始菜单的「上线助手」文件夹和桌面都有快捷方式，程序、卸载项和「应用和功能」里显示的名字都是「上线助手」。

### 8.4 升级（覆盖安装）

直接下载新版本的安装包，双击安装即可。

- 安装器会**先帮你把正在发布的隧道和它拉起的本机服务停掉**，再替换程序文件，减少「文件被占用」和半停状态。这一步**只停运行、不改设置**：隧道还保持「开着发布」，升级完成后应用会按原设置把该连的隧道重新连上，不用你一条条手动点「开始发布」。
- 你的设置、密钥、日志都**不会动**；老配置会自动升级格式，升级前还会自动备份（`config.json.v5.bak`）。
- 开机自启项会被保留（哪怕你选了「先卸载再安装」也不会丢）。
- 装的是旧版本（降级）时，安装向导会警告：新版本存的配置旧版本打不开。不拦你装，但建议装回新版。

### 8.5 卸载

1. 打开「设置 → 应用 → 已安装的应用」（或控制面板的「程序和功能」），找到「上线助手」，点卸载。
2. 卸载向导：确认页会再次说明「正在发布的隧道先停掉；应用拉起的本机服务也会停；配置和密钥默认保留」。
3. 确认页上有一个勾选框 **「同时删除配置和密钥（配置文件夹，删了找不回）」**：

   - **不勾（默认）**：卸载程序只删程序文件，配置、密钥、日志原样保留。以后重装或换台电脑还能接着用。
   - **勾上**：卸载时会把 `%APPDATA%\Shangxian` 和 `%LOCALAPPDATA%\Shangxian` 两个数据目录一起删掉（含密钥、日志、配置，删了找不回）。
4. 卸载时如果配置文件被占用没删干净，会弹提示告诉你去哪个路径手动删。
5. 便携版没有卸载程序：先关掉「开机自动启动」、退出应用，然后整个文件夹删掉即可。

### 8.6 便携版怎么用

1. 把 `shangxian-v0.6.0-portable.zip` 解压到你想放的地方（整个文件夹解压，别只拖 `app.exe` 出来，`cli.exe` 要跟它在一起）。
2. 双击 `app.exe` 就能用。
3. **数据放在解压目录的 `data` 文件夹里**（配置、密钥、日志都在里面）；整个文件夹拷走就等于搬了家。文件夹里有个 `shangxian.portable` 空文件，就是它在提醒程序「用便携模式」；删掉它，程序就变回普通方式（数据存到系统用户目录）。
4. 文件夹里带一份 `说明.txt`，写清了怎么用、怎么彻底删、安全提醒和校验方法。
5. 安全提醒：`data` 文件夹里有 SSH 私钥，别把整个文件夹发给别人。
6. 更新便携版：下载新 zip，解压到一个新文件夹，把旧的 `data` 文件夹拷进去（或者直接把新程序文件覆盖到旧文件夹上，保留 `data` 和 `shangxian.portable`）。

### 8.7 自己从源码打包（一般用不上）

普通用户直接下载 Releases 的安装包就行。非要自己打包的话，**只能在项目根目录跑**：

```bash
bash build-release.sh      # Windows 上也可以双击 build-release.bat
```

它会依次：编译命令行 → 把 `cli.exe` 放到应用要用的 sidecar 位置 → 打安装包 → 打便携包 → 生成 `SHA256SUMS`。

注意两点：

- 现在的打包配置只出 **.exe 安装包**（NSIS）和 **.zip 便携包**，**不出 .msi**。
- 不要单独在 `app` 目录里直接 `npm run tauri build`——少了上一步放好的 `cli.exe`，会打包失败。先跑 `build-release.sh` 才对。

## 九、命令行（给 AI 和脚本用，可选）

`cli.exe` 是给 AI / 自动化脚本用的遥控器：应用才是干活的那个（常驻托盘），命令行只负责查询和改配置。普通使用不需要它。

- 安装版：`cli.exe` 和 `app.exe` 装在同一个文件夹里。
- 便携版：`cli.exe` 就在解压目录里。
- 安装目录里还带两份给 AI 看的文件（便携包也一样）：`AGENTS.md`（命令参考 / 配方 / 安全红线）和 `SKILL.md`（agent 技能文件）；把这两份连同 `cli.exe` 一起交给 AI，它就知道怎么用。
- 不知道有哪些命令：`cli guide`（速查）或 `cli methods`（全部底层方法）。
- 默认中文人话输出；加 `--json` 出机器格式（成功 `{"ok":true,"result":…}`，失败 `{"ok":false,"error":"人话原因"}`）。
- 退出码：`0` 成功、`1` 出错、`2` 命令写法不对、`3` 应用没在跑（只读命令除外，会退回读旧配置）。
- 危险操作（暂停/删除隧道、删除服务/服务器、停全部、重置指纹、导入配置）在脚本里必须加 `--yes`；在交互终端会问 y/N。

**常用命令**：

```bash
cli status                  # 概览：应用 + 本机服务 + 发布隧道 + 云端服务器
cli services --json         # 本机服务清单（id、端口、状态、启动方式）
cli tunnels --json          # 隧道清单（服务→服务器、云端端口、状态）
cli servers --json          # 云端服务器清单
cli ports --json            # 本机正在监听的端口（带进程名和程序路径）
cli tunnel start <id>       # 开始发布；stop 暂停（要确认）
cli tunnel check <id>       # 去云端核对实际生效的访问保护（和界面「检查云端」同一套判定，最长约 30 秒）
cli service start <id>      # 拉起本机服务；stop 停止；edit 改配置
cli nginx <隧道id>          # 生成要贴到云端面板的 nginx 片段
cli server test <id>        # 真连一次这台服务器的 SSH（最长 15 秒，成功返回用时）
```

配免密前先用 `cli server test <id>` 确认这台服务器连得上（连不上时配免密只会白费一次密码）；配完可以再 test 一次，确认换成密钥后也连得上。

**体检 / 排查**：

```bash
cli doctor                  # 体检：应用、文件夹、SSH、端口、服务器、隧道、云端、公网、域名
cli doctor --deep           # 深度检查（连服务器和域名，慢一点）
cli doctor --strict         # 有没过就退出码 1（不算命令错误）
cli diag --out 诊断包.zip    # 打一个脱敏诊断包（不上传，只落盘）
cli stats                   # 运行统计：应用运行多久、隧道重连情况、今日重连次数
cli app update-check        # 查有没有新版本（只查，不下载、不安装）
```

**看日志**：

```bash
cli logs <隧道id> --lines 80           # 隧道日志
cli logs <服务id> --kind service       # 本机服务日志
cli logs --source all --format json    # 事件 + 应用日志 + 所有隧道/服务日志
cli logs <隧道id> --archive 1          # 看上一份轮转备份（0 当前 / 1 / 2）
```

**撤销删除**：

```bash
cli undo              # 撤销最近一次删除（= cli undo last）
cli undo list         # 看还能撤销哪些（删除后 10 分钟内、最多 20 条）
cli undo <令牌>        # 按令牌撤销
```

隧道撤销后一律是暂停状态，想继续发布再 `cli tunnel start <id>`。

**配置备份**：

```bash
cli config export --out 备份.json      # 导出（默认脱敏）
cli config export --with-paths         # 连密钥路径一起导出（仍然不含密码哈希）
cli config import 备份.json --dry-run  # 只看会改什么
cli config import 备份.json --yes      # 合并导入；--mode replace 整份替换
```

**升级 / 卸载前停全部**（安装器自己会调，手动用也行）：

```bash
cli app stop-all --yes     # 停掉全部隧道和应用拉起的本机服务（只停运行、不改设置；应用没在跑时直接退出码 0）
```

**安全提醒**：

- 别在命令行里直接写服务器登录密码；用 `cli server setup-key <id>` 从标准输入读（不回显）。
- 网页访问密码用 `cli server hash-password <id>` 或 `--access-password`，密码本身不落盘。
- 完整的命令参考和给 AI 的规矩见 `docs/AGENTS.md`。

## 十、常见问题

### 问题 0：不知道哪出问题了 → 先体检

「设置 → 体检 → 开始体检」。9 步检查会指出问题在哪，并给出「怎么办」。还不行再往下看。

### 问题 1：网址打不开

别急，按顺序查（前一步没问题再看下一步）：

| 顺序 | 检查什么 | 怎么查 | 正常应该是什么样 |
|---|---|---|---|
| 1 | 先体检 | 「设置 → 体检」快速检查 | 看有没有「没通过」的那一步，照「怎么办」做 |
| 2 | 应用还在吗 | 看右下角托盘有没有「上线助手」图标 | 有；没有就打开它 |
| 3 | 本机程序在不在 | 「本机服务」页看状态 | 在跑 |
| 4 | 程序本身好的吗 | 在电脑浏览器打开 `http://127.0.0.1:你的本机端口`（比如 `http://127.0.0.1:8188`） | 能打开 |
| 5 | 隧道开着吗 | 「发布隧道」页看状态 | 正在发布。已暂停就点「开始发布」；掉线重连中就等一会儿；出错就看 ↳ 后面的原因 |
| 6 | 云端 nginx 配了吗 | 在隧道卡片上点「检查云端」（云端配置弹层里也有同一个按钮） | 显示「云端已生效」；显示「云端没找到」或对不上就按提示重新贴片段并重载 nginx |
| 7 | HTTPS 有没有问题 | 上一步的检查结果里的红字 / 黄字 | 按提示去面板开 HTTPS、续证书、开「强制 HTTPS」 |
| 8 | 域名解析加了吗 | 这个应用查不了，得自己验证：用手机流量打开网址；或在电脑上 `nslookup 你的域名` 看指向的 IP 对不对 | A 记录已添加，IP 指向服务器；解析生效可能要等十几分钟 |
| 9 | 密码对吗 | 隧道卡片上的保护小牌就是保护方式 | 用对应的用户名密码登录 |
| 10 | 是不是缓存/网络问题 | 换一个浏览器、手机切到流量再试 | 能打开 |

**还不行**：打开该隧道的「看发布日志」，把内容复制出来；或者导出诊断包（设置页 → 关于 → 导出诊断包）。

### 问题 2：端口被占

| 情况 | 提示原文 | 怎么办 |
|---|---|---|
| 本机端口被同一台电脑的另一台服务占了 | 本机端口 30141 已经被另一台服务用了 | 到「本机服务」页编辑，换一个端口（程序真的监听的那个） |
| 云端端口被同一台电脑的另一条隧道占了 | 云端端口 19103 已经被这个服务器上的其他隧道用了 | 编辑隧道换一个空闲端口，保存后重新做一遍 nginx 配置 |
| 云端端口真的被别的程序占了 | 隧道日志里出现 `remote port forwarding failed`，卡片原因里写「端口被占」 | 应用会自动清掉「上次遗留的 SSH 连接」（只清占着这个端口、且是 SSH 的，不会乱杀别的程序），然后重连。如果写「端口被非 ssh 进程占着」，说明占它的是别的程序，应用不会动它——请换一个云端端口。「检查云端」也会告诉你端口是不是被别的程序对全网卡开放 |
| 两台电脑用了同一个云端端口 | 隧道一直连不通/掉线 | 两台电脑各用各的云端端口，不要重复 |

### 问题 3：掉线重连中

**这是什么**：你电脑和云服务器之间的通道断了。常见原因：网络波动、服务器重启、电脑休眠、安全软件拦截。

**应用会自动做什么**：

- 马上开始重试，第一次等 2 秒，还不通就 4 秒、8 秒……最长 30 秒试一次。
- 连接恢复正常后，状态自己变回 **正在发布**。
- 断掉超过 3 分钟会弹一条系统通知，标题是「**发布掉线：隧道名**」；恢复后再弹「**发布恢复：隧道名**」（可在设置页关掉，也能用免打扰时段只压掉线提醒）。
- 电脑睡醒、网络恢复后会**立刻重新连**，不用你管。

**你能做什么**：

| 想做的事 | 怎么做 |
|---|---|
| 不想等 | 点卡片上的「暂停」，再点「开始发布」 |
| 想知道为什么 | 点「⋯」→「看发布日志」，看最后几行；也可以切「只看错误」 |
| 断了很久 | 看看云服务器还开着吗、密码/密钥是不是换过、家里的网是不是断了；然后跑一次体检（深度） |

**注意**：断线期间，别人打开网址会失败（常见的是 502 错误）。这不是程序坏了，等隧道恢复就好。

### 问题 4：密码忘了

| 忘了哪个密码 | 能不能找回 | 怎么办 |
|---|---|---|
| 网址的访问密码 | **找不回**。程序只存加密结果，不存原文 | 点隧道卡片上的保护小牌（改密码）→ 填一条新密码保存；保存后会自动打开「云端配置」，**把新的密码文件行贴回面板并重载 nginx**，否则旧密码还有效；最后点「检查云端」确认 |
| 云服务器的登录密码 | 跟本软件无关 | 找服务器商家/管理员重置 |
| 免密登录失效（换了密钥、服务器重装） | 不用找回 | 「云端服务器」页 → 编辑 → 点「用密码登录一次，帮我配好免密」重新配一次 |

### 问题 5：通知不弹 / 不想被通知吵

- 先看设置页「掉线提醒」是不是被关掉了。
- 再看「免打扰时段」——这段时间只弹「恢复」，不弹「掉线」。
- 都不行就看一下 Windows 的通知权限（系统设置 → 系统 → 通知），以及是不是开了「专注助手」。
- 通知发不出去时，应用会记一条提示；掉线和恢复仍然记在标题栏的通知中心里，不会丢。
- 嫌吵但不想全关：设置页打开「免打扰时段」，设成你睡觉的时间就行；如果只是不想看应用里的小提示条，用通知中心右上角的「界面静音 1 小时」。

### 问题 6：电脑睡了 / 换了网络，要不要手动重连？

不用。醒来或网络恢复后，应用会把正在发布的隧道全部重新连上，通常几十秒内回到「正在发布」；你会在通知里看到一条一次性提示。

### 问题 7：应用崩了 / 被强杀了

- 意外崩溃：Windows 会自动把应用静默拉回托盘继续看护；本机服务不受影响。
- 10 分钟内连续崩 3 次：自动恢复会暂停并提醒你（防死循环）；手动重新打开一次应用就会重新登记。想看原因去数据目录的 `logs\app.log`。
- 任务管理器强杀、托盘正常退出：不会触发自动恢复；下次登录时开机自启会兜底。
- 强杀不会带走本机服务（保活）；想收干净用托盘「退出并停止全部本地服务」，或者重新打开应用后手动停。

### 问题 8：装不上 / 打开是白屏

1. 确认系统是 Windows 10 / 11（64 位）。
2. 确认网络能上网（安装器要下载「网页显示组件」WebView2）。
3. 还不行：去微软官网下载「WebView2 Evergreen 安装包」装上，再重新运行安装包。
4. 打开白屏、界面出不来：先确认 WebView2 装好了；还不行就卸载后重新安装一次（你的配置默认保留）。
5. 安装包提示「未知发布者」：这是没买代码签名证书的正常现象，点「更多信息」→「仍要运行」。

### 问题 9：装回旧版本后打不开配置

新版（0.6.0）保存的设置格式，旧版（0.5.x）不认。旧版会用只读模式跑：**不改你的文件**，界面弹红条提示你先升级，升级回来就自动恢复，不用重新配。解决办法就是把 0.6.0 装回来。

### 问题 10：日志太大 / 找不到旧日志

- 隧道日志超过 5MB 自动轮转，保留 `.1`、`.2` 两份备份；日志弹层的「归档」下拉能直接看「上一份 / 上上份」。
- 程序日志超过 5MB 时卡片会提示「日志太长了，只留了最近一段」，下次重启这个服务时自动轮转；旧文件在数据目录的 `logs\` 里。
- 应用日志超 2MB 也会轮转，保留两份。

## 十一、安全红线（请务必遵守）

| 红线 | 为什么 |
|---|---|
| **绝不暂停 / 重启 / 删除 pi-web 服务和它的隧道** | 那是你正在用的通道，一动就直接断线 |
| 删除本机服务或服务器前，先看有没有隧道引用 | 应用会拒绝并告诉你是哪几条，别绕过去（不要手改配置文件硬删） |
| 网页访问密码（访问保护）只显示一次，只存加密结果（bcrypt） | 忘了只能重设，别指望找回 |
| 配置文件读坏时先修好再操作 | 应用会留底 `config.json.bad` 并停掉自动保存；红条没消之前别硬改、别乱删 |
| 配免密用的登录密码只在内存用一次 | 不会落盘、不会进日志 |
| 云端保持「普通 SSH + nginx」，不装常驻程序 | 少装一个东西，少一个故障源 |
| 想让服务常在，用「开机自启 + 托盘」 | 直接退出应用 = 所有隧道全停 |
| 每个服务都加访问保护 | 「谁都能进」= 网址一泄露谁都能看 |
| 诊断包只发给信得过的人，别自己传到网上 | 包里虽然脱敏了事件和设置，但仍有你的服务器地址、域名、隧道名等现场信息 |
| 数据目录里的 `keys\` 和 `ctl.json` 别发给别人 | 那是服务器私钥和应用控制通行证 |
| 只从本仓库 Releases 下载，并核对 SHA256SUMS | 安装包没有代码签名；校验和能确认下载完整、没被换过 |
| 卸载时想清楚再勾「同时删除配置和密钥」 | 删了找不回；不勾就是保留，重装能接着用 |
